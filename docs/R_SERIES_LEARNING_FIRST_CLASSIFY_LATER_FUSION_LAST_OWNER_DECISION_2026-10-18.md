## 2. 阶段 A：R 系列逐项学习的操作与验收

每个已经立项的 R 研究按其**类型与最初问题**推进，至少明确：

1. 研究对象与第一手来源：原论文/代码/可靠数据版本、数学或行为对象、适用情境和已有竞争解释；来源拿不到时保留来源失败证据。
2. 数学机制或模型实际学习：关键变量、状态与参数、更新/预测公式、识别或计算假设；原算法的可复算实现、最小反例/测试，或数据不足时明确哪些只能从论文学习，禁止臆造实证。
3. 必要的任务内检验：使用与本研究问题匹配的数学验证、代码重跑、真假数据字段审计、合法回顾性预测/负对照；不能要求所有算法、理论、规范都具备同一种E2真人评估。
4. 研究结束时标注**学习完成的边界**：`LEARNING_COMPLETE_BOUNDED`（已明确理论、计算与特定证据）、`LEARNING_PARTIAL_SOURCE_BLOCKED`（来源/测量所限）、`ACTIVE_STUDY`、`CLOSED_SOURCE_ONLY`或`LEARNING_REVIEW_PENDING`；这些是学业/工作进度标记，**不得代替原论文科学验收状态**。正式结题须继续按研究的原定统一门槛，不能把 `E0/E1` 成功、测试通过或来源失败冒充`E2/E3`成功。
5. 每轮研究文件、代码、测试、原始出处哈希、阴性和失败，阶段交付后提交 GitHub `main`并独立读取核验。不要将一个研究任务的结果强制移植为整个模型家族或跨领域结论。

若某一研究由于源数据/身份键/测量条件有界受阻，可完成该次**可核实的理论与来源学习工作**并明确科学门未闭合，然后推进下一既定R模型。避免无限重试单个下载阻塞整个学习序列。保留未来证据允许时返回的触发条件，不能宣称外部验证完成。

阶段 A 期间只做每项必要的局部学习笔记及原研究验收、归档，不进行全库逐项重分类、跨模型合并选择或原创 PESEN 参数熔合。

## 4. 阶段 B：仅在 R 学习批次明确达到退出条件后统一分类

阶段 A 完成既定 R 学习批次且没有未处理的重要独立学习主题时，依据所有 R 包和 239 项目录重新确认真实研究覆盖，再建立统一模型分类：

- 模型或知识类型：心理机制/社会机制、数学动力学、统计预测、因果识别、测量与可靠性规范；
- 作用尺度：个人—群体/网络—制度—文化/历史，外加跨尺度必要的可观测映射；
- 结构关系：竞争、可组合、互补、冲突或只提供计算工具，防止双算同一来源信息；
- 实证地位：仅理论、synthetic、实读源码、来源E1、同源执行、不同实现、真人E2、独立实验、因果证据、前瞻验证；
- 适用规则及失败：合法前序信息、缺失/改配、时间制度、原个体身份、群体差异和负对照。

分类结果不得自动提升源研究的科学结论，也不能把重复下载/同一原文件当独立研究人数。已存知识叠加材料可供机器核对，但分类需以后阶段 B 的**最终版本R研究文件**重新核验，而非直接采用暂时工作分类。

## 5. 阶段 C：分类后才允许启动“熔炼”

在阶段 B 的模型对应、竞争/兼容关系和具体预测目标确定后，形成一个**版本化原创候选**，按“最小兼容机制→可观测量→数学一致性/可辨识性→统一简单基线与消融→适配真实来源的独立检验”逐层验证。禁止仅堆叠大量模型或用实验后的目标数据挑权重；必须保留负面结果、参数意义及跨尺度有效边界。无法验证的融合只算理论假设或教学模拟。

已有 **PESEN v0.1 作为历史冻结研究模型保持不变**；熔炼将另立独立版本与协议，在满足充分验收后才考虑任何正式升级。长期愿景仍为有限条件的群体概率预测、将来辅助现实决策，但**个人化决策系统的设计与执行继续暂缓**。
