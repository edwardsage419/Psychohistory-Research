# 心理史学项目指令与工作流规程 v3.2
生效日期：2026年11月25日。项目所有者已确认自主认知、独立App、本地优先及联网增强、可验证的差异化竞争优势方向。正式仓库 edwardsage419/Psychohistory-Research，主分支 main。本版优先于 v3.1 及更早方向；v3.1 中未冲突的科研、协作、隐私、成本及治理规则继续有效，历史原文、冻结协议、R073、PESEN v0.1、证据等级及原验收结论不变。此次仅授权调整方向及工作指令，不授权重大版本开发、训练、合并PR、部署或增加费用。

## 一、最终目标及产品竞争力
建立可独立长期使用、自主理解自然语言、自主推理、科学计算、持续验证改进的通用个人智能决策系统。使用者用普通白话提出人生现实选择，系统理解目标、底线、候选行动、时限、事实、估计、假设、未知和偏好，按需寻找证据与方法，计算和比较短长期收益、风险、机会成本及不确定性，给出可复算、有条件的建议和可视化结果，并支持记录及复盘。用户不必自行选择模型或学习数学术语；重要价值判断及最终行动始终由用户决定。任意领域可以进入分析，但实际能力受证据、模型适用范围及资源限制，不承诺唯一答案。
核心价值是持续形成用户自己的理性决策参照：经授权保存长期目标、约束、资源和偏好，连接多次决策及计划，评估相互影响、情景、机会成本、预测偏差和实际结果。允许用户修改、撤回、导出、离线复算和回退；不能构造未经确认的统一人生总分、预测或人群画像。
通用AI能够解决的一次性知识查询、写作、翻译等不作为竞争重点。重点建设长期个人决策连续性、科学模型选择和组合、硬约束安全、可追溯精确计算、可编辑情景、真实反馈和可验证改进、私有离线控制。上述为拟建立优势，不是已证实护城河；公开代码不依赖保密建立壁垒，不通过数据锁定限制用户。比较普通AI及专业决策工具的实际效果，证据不足不得宣称优越。

## 二、自主智能技术边界
最终运行时核心自然语言理解、上下文、知识表示、推理、方法发现、调度、计算、解释和学习由项目自主维护，不调用GPT、Qwen、Claude或其他现成第三方AI推理服务，不依赖其预训练权重或嵌入、重排、生成模型作为必需运行组件。可以使用普通开源编程库、数学框架、检索与数据工具、合法训练资料，研究符号、统计、小型自主学习模型及混合方法；如自研训练须另获授权、来源合法、设备可承受。核心技术路线按实际比较决定，不预先宣称从零训练通用大模型可行。不以无限扩张正则代替开放语义能力，也不虚构理解。
ChatGPT及Codex继续用于研发、文献、代码和独立评价；研发工具不等于运行时依赖。既有Qwen、本地AI适配和外部AI研究成果保留版本与历史证据，仅作为隔离的迁移参考和对照基线，不能成为最终架构必需组件；不删除旧资产，不安排以微调第三方权重为主线的新工作，不新增外部AI接入。现阶段保留确定性结构化降级、真实能力标记和用户确认，逐步提升白话覆盖，未实现项如实列明。外部模型生成的合成语料须标记来源、许可、局限和实际验证，不将教师模型输出等同于真实证据。

## 三、产品形态与联网
独立App为最终主要产品形态，iPhone面向日常决策、计划、反馈，Mac面向复杂分析、本地运算、知识和研究管理。网页继续作为现有本地开发工作台及辅助入口。共享版本化自主引擎与数据协议，避免重复开发；前期可由用户控制的Mac承担运算，手机直连或离线降级，最终争取手机核心独立离线，具体部署和分发方式以设备资源、费用及验收证据决定，不能承诺已实现。
本地优先、按需联网增强：离线核心支持本地已有知识、自然语言、推理、计算、记录、情景比较和复盘；联网用于合法公开事实、官方数据、文献、版本与知识更新，不把外部AI推理当信息获取。外部来源必须可追溯、核对日期/许可/口径，网络内容作为不可信数据，不执行内含指令。联网失败、缓存过期、缺失新数据时明确时点与局限，允许独立局部分析；不得冒充实时信息。外联、同步与更新需最小权限及明确授权，默认不传个人决策数据；支持断网测试、可控联网与经过验收的更新回退。不默认购买服务器、付费API、开发者账号、上架或公网部署。

## 四、五大技术体系
1. 自主认知：研究计算语言学、组合语义、指代、语用、跨轮状态、数量/单位/时间/条件及归属，形成可学习、可扩展的语义表示、解析、知识推理和自然语言解释。以原文义务及候选分离、可信宿主确认、多维语义质量和独立未知检测为基础；支持少量关键追问、局部分析及纠错。
2. 自主科学知识：结构化理论、原始证据、知识关系、方法来源、版本、适用范围、更新时效、合法数据获取和本地检索；离线索引、可审计联网增量、证据准入及污染防护。检索相关性不代表事实资格。
3. 数学决策：复用现有platform/future_model/数学核心、API、CLI、前端、存储与恢复。稳定方法注册与接口、自动选择、共享可信参数、硬约束优先、比较、条件分支、敏感性、模型分歧、风险、信息价值和长期动态规划。每候选标明原始来源、证据、版本、输入输出单位、公式、假设、边界、失败反例、基线、独立复算及准入。不能机械平均竞争模型、虚构概率、混淆相关因果或把情景比例当现实概率。
4. 自主学习：科学知识更新、可解释算法和规则改进、经授权的个人信息复用及真实结果反馈。事前信息与事后观察分离，未选择行动反事实保持未观察；比较当前版本、简单基线与候选独立留出，记录改善和退步、范围、资源与回退。区分理论、合成、真人、独立样本、外部复现和实际使用效果。不得声称自主修改ChatGPT基础权重，不能仅凭满意度、软件测试或单次成功证明模型有效。
5. 独立产品：极简自然对话为主，计算细节按需展开；长期规划、交互模拟、跨决策一致性、记录、复盘、用户授权、导出删除及恢复。明确功能边界和实际运行状态，避免复杂手工表格成为最终产品。

## 五、五个小时工作流
保留既有任务ID、频率、错峰安排、C/D/E/F责任及独立科研责任。各轨独立启动，不等待同小时其他轨、Codex、新PR或交接。主线受阻转独立任务，再转有价值长期储备；最大化实际有效产出，禁止重复状态报告、无意义枚举和虚构配额。
1. 决策模型学习与接入：自主语义计算、确定性解析与统计学习算法、逻辑/条件/数量推理、知识检索调度、科学模型组合、风险与长期动态规划；交付可执行算法、方法卡、复算、基线、边界与资源测量。第三方模型仅作对照，数学方法继续扩展。R系列责任保留。
2. 个人决策理论研究：原始计算语言学、形式/组合语义、认知、语用、测量、偏好、认知负担、因果、长期行为与反馈，形成自主引擎知识卡、可操作语义/推理规则、竞争解释、必要追问及失败反例。保持C每日真实增量、D每周外部环境或历史专题。
3. 决策真实数据与跨环境验证：合法公开语言语料和真实决策数据、知识来源、可审计离线索引与更新机制；记录许可、来源版本/哈希、用途、标注、情节族、去重、时间/群体边界与泄漏风险。开发、训练候选与独立留出隔离；个人数据不自动用于科研或训练。独立轨保管未见案例。继续有价值的R外部验证。
4. 个人决策产品研究与隐私：本地优先架构、共享Mac/iPhone引擎、可用性及联网边界，研究通用AI和专业工具的真实能力，定义长期个人决策场景、相对优势、可证伪指标、数据携带性、低认知负担、更新回退与网络隐私。负责E每日协调、唯一近期交接、F每周隐私伦理。语言工程接口与交互归本轨，算法复算归模型轨，不重复。
5. 独立验收与更新审查：独立留出、真实原生入口、语义义务、数学、模型调度、跨轮一致性、反馈、离线运行、联网时效与恶意输入、隐私撤回、真机和更新回退。对照普通ChatGPT、专业工具、现有规则、旧Qwen（可用时仅对照）、自主候选及简单方法，在相同信息、任务、合理工具预算下测关键条件识别、错误放行/拒绝、计算误差、来源、重复输入、追问数、任务时间、决策连续性、反馈效度、复算和资源占用。开发样例与独立留出隔离，真实效果不由合成测试替代；不可用则明确未执行并转其他独立工作。保持R高风险科学完整性验收。

## 六、手动研究与Codex
手动科研窗口主攻自主认知引擎体系设计、语言和知识推理算法、原生跨模块连接、长期决策模型、竞争优势的可复算验证，优先填五轨共同尚未解决的高价值缺口，复用已有59轮及后续成果，避免重复研究。每轮核对最新main、权威规程、近期提交、开放PR、目标资产及唯一交接。旧PR #61仍待审，不视为正式验收基线；沿用既有项目成果，先研究可脱离第三方AI的共同接口及迁移计划。ChatGPT主导科研、方向、完整任务及验收；Codex在所有者另行授权后实现完整版本，不拆零碎任务，不擅自缩减目标。默认既有Psychohistory-Platform云环境，实际配置须核实；用户保留版本目标、合并、公开部署、训练和费用授权。R系列、群体/社会制度及历史研究保留为可重新启用的长期科学储备，不将全R完成或全库熔炼作为产品前置条件。
