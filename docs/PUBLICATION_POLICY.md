# 公开归档与证据政策

首批公开归档仅包含项目自行编写的研究文本、数值派生摘要、计算/测试脚本，以及三份已验证的历史研究包 ZIP。ZIP 保留历史字节，包含的文件以随包内 SHA256SUMS.txt 为准。

1. 研究编号完整不代表资料归档完整，也不代表一轮研究已经成功识别心理机制。历史轮次仅有摘要的，在此标为 `HISTORICAL_RECORD_ONLY`。
2. 研究源码、测试、真实人类数据证据等级分别标记；构造数据测试只是软件质量证据。
3. 未核实许可证的第三方数据不在本仓库重新分发；只记录原作者链接与 Git 对象 SHA。
4. 报告的原始来源、时间顺序、训练/测试隔离、随机化单位与缺失问题必须保留。
5. GitHub 公共仓库只允许匿名研究结果；禁止上传密钥、私人邮件、个人身份识别材料与未经确认可公开的数据。
6. 本项目尚未选择开源许可证，公开可见性本身不授予重用、再分发或修改许可。未来可由仓库所有人独立决定许可证与贡献条件。

创建日期：2026-10-15。长期方向：五年内建立有限领域可检验研究体系，十年探索谨慎的跨尺度联系。PESEN v0.1 继续冻结。
