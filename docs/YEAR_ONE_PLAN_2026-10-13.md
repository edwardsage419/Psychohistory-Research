# 心理史学研究：第一年执行计划

版本：1.0  
制定日期：2026 年 10 月 13 日  
规划期：2026 年 10 月 13 日至 2027 年 10 月 12 日  
性质：学习与研究工作的建议性执行计划。阶段依据能力与证据推进，时间安排可以延长。  
上位路线：五年建立有限领域研究体系，十年探索心理机制与历史演化的连接。  
主轴：计算社会科学。首个正式方向：群体规范形成与行为扩散。  
资源约束：每周最多约 10 小时，全年按 48 个学习研究周和 4 个机动周预算。

## 1. 执行结论

第一年目标是建立独立开展小型可复现研究的能力。禁止用阅读量、模型数量、代码行数替代研究进度。

**本年必须形成四类成果：**

1. 一份能够持续更新的知识地图，覆盖研究设计、测量、统计推断、简单网络机制及其边界。
2. 一份使用公开授权数据或教学数据的可复现数据分析报告。
3. 至少三张有证据字段的机制卡片，以及一个可复现的行为扩散教学仿真。
4. 一份比较至少两个竞争机制和一个基准模型的技术报告，明确模拟条件、失败案例和实际证据缺口。

这些成果属于方法训练，不能自动视为发现真实社会规律。第二年是否开展特定论文的复现，取决于数据、方法细节、许可和技能准备情况。

## 2. 研究对象及概念边界

长期研究问题：个体的认知、决策和学习如何经由社会互动与制度条件，产生群体行为，并在特定条件下影响长期变化。

第一年收窄成问题：**给定相同的初始采用比例，个体采用规则与互动网络结构如何改变行为扩散的速度和最终范围？**

第一年不宣称解释整个社会历史，也不宣称任何固定的普遍临界比例。

明确区分：

* 行为采用：个体在模型中选择某一行动。
* 行为扩散：采用行为在群体中随时间传播。
* 行为惯例或协调：成员因预期他人采取某行为而协调。
* 社会规范：还涉及人们对“应当怎样做”的规范性预期及相应的条件性遵从。

仅观察采用率上升，不能断定已形成社会规范。未来若研究规范形成，需要另行测量实际行为预期、规范性预期以及在不同社会预期下的行为响应。

## 3. 时间预算

总预算为 52 周 × 10 小时 = 520 小时，其中 48 周 × 10 小时 = 480 小时用于已安排的学习和研究，4 周 × 10 小时 = 40 小时作为机动容量。机动容量并非额外的强制工作。

建议典型周分配：

| 活动 | 每周时间 | 要求 |
| --- | ---: | --- |
| 方法及理论阅读 | 3 小时 | 做概念区分，摘录可信来源 |
| 数学及统计练习 | 2 小时 | 手工例题与代码校验互证 |
| 编程与数据处理 | 2 小时 | 保留可运行脚本及环境信息 |
| 研究实践 | 2 小时 | 逐周推进同一个受限问题 |
| 记录和复核 | 1 小时 | 记录决定、反例和未解问题 |

在统计薄弱的月份可将阅读或实践时间转给统计；单周上限不变。计划每 4 周评估一次，不能因为任务没完成就默默扩大长期负担。

## 4. 全年四季度路线

### 第一季度：研究方法与分析基础（第 1 至 13 周）

学习：研究问题与假设、心理测量基础、描述统计、概率与抽样、相关与因果、Python 数据整理及可视化、简单网络指标。

交付：问题说明 v1；数据字典；一个完整的探索性分析 notebook 与脚本；一份 3 至 5 页的学习研究报告；Git 仓库与环境说明。

验收：他人按 README 能复跑；能准确区分研究对象、操作化变量、样本和总体、相关性与因果解释。

### 第二季度：个体与群体机制（第 14 至 26 周）

学习：启发式与决策、社会学习、同伴影响、协调、基本博弈、图论指标、网络结构及实验研究阅读方法。

交付：至少三张机制卡片；一份机制比较表；两种基本网络的结构分析；一份给定论文的研究设计拆解。

验收：每张机制卡片能指出可观测结果、机制假设、与替代解释区分的方式、证据类型与外推限制。

### 第三季度：教学仿真（第 27 至 39 周）

学习：独立采用基准、简单传播、复杂传播或阈值规则、同步与异步更新、Monte Carlo 重复运行。

交付：行为扩散教学模型；不少于三种采用规则的同条件比较；测试代码与最小文档；结果图表。

验收：固定随机种子时完全可复跑；换随机种子能报告结果差异；能在参数极值和无传播条件下检查程序是否符合预期。

### 第四季度：模型检验与报告（第 40 至 52 周）

学习：参数敏感性、基准比较、简单不确定性量化、过拟合与可识别性、复现研究写作。

交付：技术研究报告 v1；失败案例登记；模型适用边界；第二年论文复现候选及数据可得性审查。

验收：清楚区分模拟中观察到的规律与现实中的实证证据；能说明哪些差异由设计假设造成，哪些问题仍需真实数据检验。

每季度最后一周为机动、补课与证据审查周。没有达到验收条件时优先延长阶段，不以日历日期自动升级。

## 6. 教学仿真最小研究设计

### 6.1 研究问题

在给定群体规模、网络和初始行为采用比例下，不同个体规则是否导致不同的扩散轨迹？网络结构改变时差异是否稳定？

### 6.2 预先登记的三个竞争模型

**M0 独立采用基准：**尚未采用的个体每期按固定背景概率采纳，不受邻居影响。

**M1 简单传播：**个体接触越多已采用邻居，采纳概率越高；例如以每个已采用邻居独立产生一次影响的方式计算本期采纳概率。

**M2 阈值采用：**当已采用邻居占其邻居的比例达到个人阈值，个体在该期采用。零邻居节点单独定义处理规则。

所有模型都必须先明确是否允许撤回采用、何时更新状态、如何设置初始采用者，比较时保持共同条件。阈值规则和单次接触规则分别体现不同的简化机制，不必预期一定谁胜出。

### 6.3 最小自变量与结果指标

自变量：初始采用比例；网络结构；模型规则；阈值或接触强度。

结果：每期已采用比例；最终采用比例；达到某一预设覆盖率的时间；不同随机重复间的分布。

控制：相同节点数、相同初始采用者的抽取逻辑、预定随机种子集合、相同运行上限及记录格式。

演示规模可以设为 200 个节点，每组参数重复 100 次。数字仅是教学预算，正式分析前应由计算时间和所需精度重新评估。

### 6.4 最低检验

1. 固定种子两次运行得同一输出。
2. 无初始采用者且无背景采用时，不出现无因采用。
3. 全员初始采用时，最终采用比例始终为 1。
4. 没有边的网络中，纯邻居传播不会发生。
5. 改变更新次序后如结论变化，必须记录为实现依赖。
6. 不能从合成数据的拟合结果声称已验证人类心理机制。

### 6.5 模型判断标准

第一年以内部一致性、透明性、可复跑性、对假设的敏感性作为判断重点。有真实观测数据时再引入外部预测性能和机制证据，不借助额外自由参数实现无约束的拟合优势。

Centola 等（2018）关于社会惯例变动的实验可以作为研究设计阅读材料。其特定实验情境的临界行为不应直接视为所有群体行为的普遍阈值。该论文原始实验数据与完整复现材料的实际可得性需要在第二年开始前核实。

## 9. 工具策略

首年坚持少量工具：Python 3、venv、Jupyter、NumPy、pandas、matplotlib、SciPy、NetworkX、pytest、Git。第三季度确实遇到主体建模需求后再评估 Mesa 或 NetLogo，避免提前增加依赖。

在 Linux 环境首次建立最小 Python 项目，可使用：

```bash
mkdir -p psychohistory-research && cd psychohistory-research
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas matplotlib scipy networkx jupyterlab pytest
python -m pip freeze > requirements-lock.txt
printf '.venv/\n__pycache__/\n.ipynb_checkpoints/\n' > .gitignore
printf '# Psychohistory Research\n\nFirst-year learning and reproducible modeling.\n' > README.md
git init
```

命令假定系统已经具备 Python venv 和 Git。如果 `python3 -m venv` 报缺失，应先使用系统包管理器安装对应 Python 版本的 `venv` 系统包。为可复现运行保留 Python 版本、包版本、随机种子、系统环境概要和数据许可。`requirements-lock.txt` 可以作为起始快照，跨操作系统时可能需要单独测试兼容性。

## 10. 推荐学习资源与阅读顺序

优先少而完整，不需要在第一年读完每本书。

1. **OpenStax, Psychology 2e**。先读 Research Methods 相关章节，理解研究设计、实验与观察研究的差别。https://openstax.org/books/psychology-2e/pages/2-2-approaches-to-research
2. **Russell Poldrack, Statistical Thinking for the 21st Century**。第 1 至 10 章和第 17 章优先。https://statsthinking21.org/
3. **Matthew Salganik, Bit by Bit**。选择研究设计、观察行为、实验、伦理相关章节。https://www.bitbybitbook.com/
4. **Albert-László Barabási, Network Science**。第二季度开始阅读基础图论和网络结构章节。https://networksciencebook.com/
5. **The Turing Way, Guide for Reproducible Research**。从第一周开始查阅版本控制、记录和研究环境。https://book.the-turing-way.org/reproducible-research/reproducible-research/

## 11. 质量审查与升级门槛

### 每四周审查一次

回答以下六个问题：

1. 本月是否提出或澄清了一个可检验问题？
2. 本月有哪些新增证据，哪些内容仍只是直觉或模拟假设？
3. 研究成果能否由干净环境复跑？
4. 变量的测量与心理概念是否有实证对应？
5. 是否有竞争解释或明确的反例？
6. 接下来的学习是否针对当前能力瓶颈？

### 第一季度结项门槛

能处理一个有文档的开放或教学数据集；有明确变量字典、基本图表、简单统计分析、不确定性与局限说明；脚本和运行说明可复跑。达不到时延长 Q1。

### 第一年度结项门槛

必须具备一份可复跑的技术报告及代码；至少比较两个竞争机制和独立基准；记录重复运行分布与至少三个反例或边界条件；拥有文献及方法来源清单；能够明确说明模拟机制与真实人群证据之间的距离。

### 第二年进入条件

至少找到一项研究的可读论文、足够明确的方法信息及合法可得的数据或实验材料；已经掌握相关分析方法；能够预先写出要核验的主要结果。如果没有条件充分的目标论文，则继续方法训练和候选筛选，不假装完成外部复现。

## 12. 数据伦理与推论底线

使用公开或已授权的数据，尊重隐私、版权、个人敏感信息与研究伦理。不要未经必要审查就开展真人干预或采集可识别心理特征。跨群体和跨时期研究需警惕测量不一致、选择偏差、历史资料缺失、生态谬误与事后挑选解释。

报告始终分开标记：理论假设、模拟结果、观察关联、因果证据、外部验证、尚未解决的不确定性。

## 13. 立即执行的第 1 周任务

1. 用一句话写下最小问题：“在相同的初始采用比例下，两种邻居影响规则是否产生不同扩散曲线？”
2. 创建最小 Git 工作目录、记录 Python 环境与首次提交。
3. 阅读 OpenStax 心理学研究方法，写 300 至 500 字比较实验与观察研究能回答的问题。
4. 阅读 Poldrack 的数据、变量和描述统计入门章节，选一份课程示例数据做读取与绘图。
5. 建立研究日志，记录三个尚未获得证据的假设、一个可能的反例、下周最需要补的能力。

**本周成功标准：留下可检查的文件，先不制作大型平台，不扩张到历史预测。**

## 14. 与长期总纲的关系

本文件仅细化第一年；保留总纲中的个体、群体、制度与环境、历史演化四层。认知、决策和学习是未来机制来源，社会网络和规范演化是首个受限应用场景。计量、复现与因果识别贯穿各阶段。到第三年是否形成原创局部模型，由第二年研究复现的可靠结果决定。后续是否进入历史研究，由多情境外部验证、可比较的历史资料和明确的推论边界决定。
