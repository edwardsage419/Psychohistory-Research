## 原著核心命题及互相竞争的解释

1. **Geertz 1972的解释性命题。** 斗鸡中的中心赌注由双方联合支持者形成，通常为等额；周边下注是个人之间按非等额赔率进行。较高中心赌注与更仔细的鸡只配对、更大的参与和更强的身份/亲属群体卷入相联系。作者认为地位竞争在此被表演、观看、感受，斗鸡作为对既有社会等级的象征性评论；作者在重刊pp79–83明确区分地位的象征表演与实际社会流动。其研究对象为1958年Tihingan及周边活动，文本多次以巴厘社会整体表述，跨村和跨时代外推需独立验证。
2. **Geertz的行为机制具有观察边界。** 重刊p68脚注15明确说赔率随人群变化的精确动态难以由一名田野工作者观察，需要多观察者及记录。文中“意见领袖带动赔率”的机制是作者的民族志判断，没有逐次个体出价、社会网络、干预或因果识别数据。不能从57场结果推断参与者的真实内在效用或证明文化意义是下注的唯一动机。
3. **Roseberry 1982的独立竞争解释。** 原刊pp1020–1024指出女性被排除在斗鸡之外，但市场与交易、税收、殖民禁令、阶级/种姓、政治权力及文化实践的历史生产仍影响这项活动。pp1025–1027主张追问谁制作、传播、改变文化形式以及谁从中受益。其论证针对文化作为静态文本的解释边界，并未提供新的巴厘随机实验或直接推翻Geertz全部象征观察。Roseberry亦明确承认Geertz提供了有价值的细致民族志。
4. **2026年的田野记录来源争议。** Schulte Nordholt出版者摘要称：作者比对Clifford与Hildred Geertz此前未公开的田野笔记，发现Geertz 1972开场关于被冷落、逃避警方与次日被热情接纳的叙述，在事件时间线与后果上存在重要不一致。此处只能登记为**2026作者在正式期刊摘要中提出的档案核查主张**。未经2026正文与原笔记逐项核验，无法判断各处差异大小、是否存在合理叙述压缩、以及它们是否影响关于下注与身份关系的其他观察。开场叙述证据链与57场下注资料证据链应分别审查。
5. **竞争机制保留。** A象征性地位表达；B市场日交易与经济机会；C殖民/独立后禁令改变可见性及参与者选择；D男性场域的性别权力；E民族志作者叙事选择与回忆。它们可以共存或彼此冲突，现有材料不足以唯一识别其相对贡献。不能把“文化作为文本”自动变成统一可计算模型。

## 数值核验与新的有限统计更正

Geertz重刊p69脚注16记录57场：高于60 ringgits 的中心赌注组为热门12、冷门11，共23场；低于该阈值组热门21、冷门13，共34场；合计热门33、冷门24。极端子组大于100 ringgits 为7/7共14场，小于40 ringgits 为19/10共29场。这是**作者汇总的观察数字**，底层逐场原始记录未提供，本轨没有独立数据复算。

在事先固定阈值、各场独立、零假设热门获胜概率0.5的人工二项模型下，单侧精确尾概率
P(X>=k|n,0.5)=sum_{j=k}^n C(n,j)/2^n。
对34场中21次热门胜，精确单侧p=0.1147405065；对29场中19次热门胜，精确单侧p=0.0680229738。原文脚注16给出的约0.08与0.05属于正态近似的单侧尾概率，离散精确尾概率略大。该差异是**本轮对作者已公开汇总数据的统计计算补充**，不代表作者原始数字录入错误，也不能证明或证伪地位解释。阈值是否事后选择、场次独立性、鸡只配对、群体重复参与、未记录混杂均未识别。

可复核标准库代码：

```python
from math import comb

def exact_upper_tail(n, k):
    return sum(comb(n, j) for j in range(k, n + 1)) / 2**n

assert (12 + 11, 21 + 13, 23 + 34) == (23, 34, 57)
assert (7 + 7, 19 + 10) == (14, 29)
assert (12 + 21, 11 + 13) == (33, 24)
assert abs(exact_upper_tail(34, 21) - 0.11474050651304424) < 1e-14
assert abs(exact_upper_tail(29, 19) - 0.06802297383546829) < 1e-14
```

## 适用层级、测量和证据限制

个体层：下注偏好、风险与身份认同仅有田野叙述，缺逐次心理测量。
