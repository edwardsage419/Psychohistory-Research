作者资料：ICRISAT布基纳法索1981–1985四年农户面板，本研究使用1981–1983三个农业季；原调查150户、6村、3农业气候区，432个家庭年度观察、4655个地块观察。原文p1016指出其中243个家庭年度具有男女分别管理相同作物的地块，共1723个地块观察。该比较子集占全部地块观察约37.014%；地块观察不等于4655个独立家庭或独立随机试验。家庭界定依赖共同生产消费及模糊情况下户主判断，可能影响观察单位。

## 原始数据的方向反转与研究假设

1. p1019 Table 1原始无条件均值：男性管理地块产值79.9千FCFA/公顷，女性管理地块105.4千FCFA/公顷，女性高25.5千，约为男性的1.31915倍；男性平均地块0.740公顷，女性0.100公顷。p1020 Table 2显示作物组合不同，不能将原始均值当作同等土地与同等作物的性别生产率。
2. p1022 Table 3列1在家庭×年度×作物固定效应及地块大小、土壤、地形、位置控制下，女性管理地块系数为负27.70千FCFA/公顷（t=负4.61）；原文将其相对全地块平均约90千的量级解释为超过30%。Table 3列5采用不同CES规格，性别系数负0.20（t=负3.56），作者p1020称约20%下降。原始均值与条件估计符号相反；此处同时改变比较样本与控制条件，不能仅凭两项汇总将其归为纯粹作物组成造成的Simpson悖论，也不能将负27.70直接说成随机干预效果。
3. 原文§II pp1013–1015式(1)–(10)：同一作物使用共同、凹的生产技术G^k，给定家庭内该作物的男性与女性劳动总量，帕累托有效配置须解决跨地块总产出最大化问题。相同地块质量和面积、内点解及共同技术下，边际劳动产出应在地块间相等，导出同等地块同等产出条件。经验式Q_htci = X_htci β + γ Gender_htci + λ_htc + ε_htci，模型的可检验限制为γ=0。若技术、土地质量或非凸固定成本假设不成立，该限制不必成立。作者自己在§V讨论这些竞争条件。
4. p1028 Table 5列2还报告在男性管理地块中，户主相对其他男性成员的系数16.42（t=1.96），作者解释为约18%的产出差距。性别之外存在代际及家庭权力层级的候选机制，不能用单一性别偏好解释全部资源分配。
5. p1040作者以Table 9的CES估计重分配已投入劳动与肥料，得到混合性别管理的家庭年度作物组平均潜在增产5.89%（SD4.7%）。这是生产函数、技术与重分配可行性假设下的模型反事实，分母是指定作物组的产出。p1040的村庄层面13%（SD6%）对应跨家庭同作物重分配，分母与可行集合不同。不得将5.89%写成全国家庭或全国农业真实已验证的损失，也不能把13%与5.89%当作同一随机试验的处理组比较。

## 竞争解释、反例与适用范围

原作者§V pp1033–1037承认未观测土壤质量可能同时决定管理者与产出；p1033脚注11甚至构造了婚姻市场上土地隐藏质量与管理性别相关、但资源配置仍有效的理论世界。其他竞争机制包括育儿与农业共同生产、固定路途成本造成非凸性、不同管理者使用不同生产技术。作者对近宅地块、育儿劳动力、CES生产函数做敏感性分析，仍未完全消除不可观测土地质量与土地分配内生性。p1035–1036 Table 8近宅子样本的负系数保留；p1039 Table 9不同性别技术差异的部分交互项并不稳定显著。p1041–1044作者提出个体土地控制、租佃权不稳与劳动交易成本可能阻碍家庭内部有效交易。这是竞争机制解释，不是随机识别的唯一原因。
