## Question and finite design
For the four unchanged R330 memory instances, how does uncertainty in an observed binary query cue affect action selection, and does averaging already normalized action scores differ from normalizing averaged instance weights? Keep the 16 fixed utility histories, decay d in {0,1}, observed cue o in {0,1}, and fixed binary true-cue prior P(z=0)=P(z=1)=1/2. Symmetric measurement error e in {0,1/4,1/2} gives P(z=o|o)=1-e and P(z=1-o|o)=e. Thus exactly 16*2*2*3=192 worlds. No participant data, training, fitting, randomization, or model update.

For each true cue z and action a, calculate original R330 normalized retrieval score S_a(z)=sum_i w_i(z)u_i / sum_i w_i(z), restricting i to action a, with original w_i(z)=(1 if cue_i=z else 1/2)*(5-t_i)^(-d). Posterior score M_a(o,e)=(1-e)S_a(o)+e S_a(1-o). Choose A if M_A>=M_B, otherwise B. Compare naive observed-cue choice N_a=S_a(o) and alternative pooled-weight score P_a=(sum_z P(z|o)sum_{i:a}w_i(z)u_i)/(sum_z P(z|o)sum_{i:a}w_i(z)). Record both alternative choices without claiming any is a human cognitive model. For each world record original R330 scores for both cues, M/P scores, choices, exact rational strings, and disagreement indicators. Serialize stable JSON with sorted keys and compact separators, newline terminated.

## Precommitted checks and falsifiers
192 unique (history,d,o,e) worlds; 64 e=0 worlds must equal original R330 scores and choices. At e=1/2, M choices must be independent of observed cue for each (history,d). At d=0, pooling and score averaging are expected to coincide because action-specific total retrieval weight is cue-independent; verify equality. All scores within [0,1]. Independently re-enumerate via separate no-import algebraic implementation and compare all fields. Deliberate corruption of each of: missing world, duplicate world, M score, pooled score, choice, e label, source provenance, and E1 evidence label must be rejected. If any check fails, report FAIL and preserve negative evidence. Summarize counts by e and decay and give at least one concrete counterexample if pooling and score averaging differ. If none differ, report null result. No post-hoc threshold changes.
