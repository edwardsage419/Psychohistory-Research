## Frozen universe and formal contact semantics

1. Exactly 3 labeled artificial nodes {0,1,2}. Available unordered contact dyads in fixed indexed order: edge0=(0,1), edge1=(0,2), edge2=(1,2).
2. Three strictly ordered time stamps t=1,2,3. At each time exactly one edge (index 0,1,2) is active, each independently allowed to take any of the three identities, including repeats. Enumerate 3^3=**27 distinct contact schedules**, in lexicographic base-3 order id0..26. Exactly **81 original event source rows**, one for each schedule-time.
3. Each event is instantaneous and undirected for message transmission, meaning if source message has reached either endpoint **before** that contact, the other endpoint may receive it at that timestamp. The transfer in one contact is at most **one hop**; newly receiving endpoint cannot transmit on the same event, and strict temporal paths must use strictly increasing contact times. Nodes can retain a message and wait.
4. Evaluate exactly 3 origins per schedule at initial t=0. Each origin initially holds message at time0, every nonorigin initially unreachable. Output **81 schedule-origin outcomes**, with earliest arrival times 0..3 or null, temporally reachable set, reachable count, and static aggregated graph reachable set if all contacts are treated as permanently active. Static reachability computed via union of all temporal edges regardless of order.
5. Require temporal reachability be a subset of static aggregate reachability for every schedule-origin; when all events use one edge, exactly its two endpoint nodes reach one another but third isolated (other origins may remain isolated). Check each schedule has exactly 3 source rows and all 27 schedule triplets are present; all 81 origin runs present.
6. Frozen temporal order witness schedule id18, temporal dyad indices (2,0,0) i.e. contacts (1,2) at t1 then (0,1) t2 and t3. In the aggregate static graph, every node reaches every other. From origin0, earliest arrivals are [0,2,null]; origin2 can reach node0 by t2. Thus static connectivity overstates 0→2 time respecting reachability and the temporally reachable relation is directional even though every contact was undirected.
7. Compute number of ordered origin-target pairs where static says reachable but temporal says unreachable over the entire fixed 27-world corpus. Exclude origin=self; no stochastic probability, confidence interval or real forecast accuracy. Compute any average only explicitly denominator with counterfactual worlds.
