- PATH4 edges {(0,1),(1,2),(2,3)}, degrees (1,2,2,1), total directed neighbor pairs6.

Frozen update **node-site asynchronous rule** (not edge-site rule): choose target node i uniformly probability1/4, then choose neighbor j uniformly probability1/degree(i), set target's state to currently observed state at j, leave all other nodes unchanged; no simultaneous updates, no self-links, no mutation, no stubborn nodes, no selection. Every (initial 4-bit state, graph) pair is an artificial world, **16×3=48 worlds**. For each world enumerate **all directed (target,neighbor) pairs**, each of known probability1/(4degree(target)), total 16×(6+8+12)=**416 fully labeled artificial source rows**. Each source row records topology, edge set, degree vector, initial bits, target/neighbour indices, copied neighbor bit, next complete bits, event probability, initial and next unweighted opinion-1 fraction, initial and next degree-weighted opinion-1 fraction, aggregated exact expectations of both quantities per source world, and whether the update changes the target state. These are not 416 real people, ballot choices, experiments, separate network runs or observations.

Frozen exact identity:
Unweighted density U(x)=(x0+x1+x2+x3)/4.
Degree-weighted density W_G(x)=sum_i degree_G(i)*x_i / sum_i degree_G(i).
For every undirected connected graph and initial state under site-target-uniform copying, E[W_G(X')|x]=W_G(x): E increment is (1/4 sum_degree)sum_i sum_(j neighbor i)(x_j−x_i)=0 by undirected edge cancellation. On regular CYCLE4 and COMPLETE4 all degrees equal, W_G=U and E[U(X')]=U. On irregular PATH4 **unweighted U is NOT necessarily conserved** (do not claim it is).
