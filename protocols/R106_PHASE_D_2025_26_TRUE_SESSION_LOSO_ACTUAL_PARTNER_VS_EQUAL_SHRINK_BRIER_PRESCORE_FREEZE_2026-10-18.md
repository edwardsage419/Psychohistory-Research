## FIVE FIXED candidate predictive models; primary equal-shrinkage test

For each eligible current binary target `Y(i,t)=original left(i,t)`, define lag `O=left(i,t-1)` and observed real counterpart lag `P=left(j,t-1)`. Denote `q_{-s,k}` a fixed other-source-session pooled Bernoulli pseudo-count estimate for **source practiceperiod = k**, excluding the **ENTIRE target original source session s** (and all its persons/rounds). Precisely `q_{-s,k}=(1+sum_{all source rows with sessionid≠s, practiceperiod=k}left)/(2+n)`. If no other source session has a row for that specific stage period, this is 0.5. Although pseudo-counts are fixed and avoid division by zero, this is a **retrospective across-session time-indexed reference**, not a calendar prospective forecast.

At target practiceperiod `k≥2`:
- **M0**: `q_{-s,k}`, contemporary other-session same-stage control only.
- **M1**: `O`, focal person's observed previous action only.
- **M2**: `0.5*O + 0.5*q_{-s,k-1}`, **matched-shrinkage control** using other-session pooled previous-stage action rate.
- **M3**: `0.5*O + 0.5*P`, true observed previous partner action at identical own-weight.
- **M4**: `0.5*O + 0.5*q_{s',k-1}` where `s'` is the **first cyclic next source sessionid after s in sorted 26 actual source sessions** (wrapping), with only its own previous stage period k−1 real source action pooled and fixed pseudo-count `(1+sum)/(2+n)`. If no donor stage period exists, 0.5. This is a deterministic unrelated source-session partner-history placebo; donor source session, person and actions are never selected or reweighted on heldout score.
