# R173 计算前冻结协议：EA005 对 EA006 的跨社会预测关联

日期：2026-10-21。数据结构预验收已完成；本协议在任何 EA005 与 EA006 真实关联评分之前冻结。对应原目录 P1/07-015 Cross Societal Comparison Models。此文件是研究者自行设计的**条件关联预测**研究协议，不代表 Murdock、White、Kirby 或其他原作者的原研究模型。

## 不可更改输入

来源 D-PLACE/dplace-data Git commit `9bfed2c8c206be00f55f71516f262bbca2234e5a`，原始 EA 六文件固定 Git blob 与 SHA256 由 R173 先前来源审计验收。仅用原始 `datasets/EA/data.csv`、`societies.csv`、`societies_mapping.csv` 和 `datasets/SCCS/societies_mapping.csv`。实验自变量 `EA005`（农业生计依赖，0至9编码，序数）；输出变量 `EA006`（婚姻交易类型，1至7编码，**名义分类**）。不将 EA006 编码视作高低顺序。科学问题限定为两种文化变量在同一民族志编档中的关联与留一社会预测力；不能反推心理因果、制度影响或历史机制。

社会观测单位为 `soc_id`，每个社会每变量必须恰好有一条原始行，编码落在以上固定合法集合。NA、空值、重复原始行、不合法代码均剔除，禁止挑一条偏好的重复记录或替代填充。SCCS 样本严格取 `EA/societies_mapping.csv` 与 `SCCS/societies_mapping.csv` 互为反向且唯一的一一对应 ID。审计已验证 186 对无冲突，主样本两变量完整 186 社会。副样本为全EA 两变量完整 1271 社会，两者高度重叠，**不能当独立复现**。

原始 `year` 与 `main_focal_year` 不做混合填补。所有有效社会都纳入主样本；另执行事先指定的完整年份敏感性：只保留两个变量原始行和社会表的四位年份均已观察的社会。年份只用于样本门控，禁止作为预测变量或用于后验筛选模型优劣。现有审计对有效数据的年份覆盖已经可见，以下评估仍不得因观察到关联结果而改变口径。

## 冻结两种模型

以目标编码 `k∈{1,...,7}`、农业编码 `x∈{0,...,9}`，对每个测试社会 `i`，训练集为同一选定样本的其他全部社会（严格 leave-one-society-out）。定义训练集数量 `n`、目标类别频数 `n_k`、农业编码频数 `n_x`、二元频数 `n_xk`。

* M0：训练折总体婚姻类别分布，`p0(k)=(n_k+1)/(n+7)`，七类别均匀 Dirichlet 先验伪计数各为1。
* M1：给定农业编码的条件婚姻类别分布，`p1(k|x)=(n_xk+10*p0(k))/(n_x+10)`。固定收缩强度10，不在数据上调参。M1使用十种农业编码作离散类别，不强加线性、单调或婚姻类别序关系。

主评价每社会自然对数损失 `-log p(k)`，总指标为全样本简单平均。提升 `Δ=mean(loss0-loss1)`；正数表示 M1 相对 M0 的留一社会预测损失较低。另报告每社会概率预测及其完整留一折 `p0,p1`、类别实际值，以独立复算。不可仅比较训练集内关联度声称预测。

## 完整固定评价集合与不确定性

1. 主样本 SCCS 186 人，输出 186 行留一社会概率；副样本全 EA 1271 社会，输出 1271 行，不将它视为第二独立数据集。
2. 再对 SCCS 和全EA分别施加完整年份敏感性（四位年字段都可用）。分组样本无测试前最小数门槛，不做基于评分选择。
3. 针对每组 `Δ`，固定种子173、2048次对**已经留一评价所得的逐社会配对差值**进行单位社会重抽样，报告2.5%与97.5%最近阶经验分位数。此区间仅属于简单社会独立假设下的探索性描述，未调整语言家族、地理距离、同源文化、编码不确定性、抽样机制。
4. SCCS 主样本额外作199次固定种子173的 EA006 目标标签随机置换，保持 EA005 及两变量边际频数，重新完成全部留一折和损失差值。报告原始提升相对置换分布的位置和两侧经验比例，**明确只作为天真可交换性对照，不可当解决 Galton 问题后的有效统计显著性**。
5. 两种独立计算路径必须得到逐个测试社会的同一 `p0,p1` 值：A从原训练折重计数，B从全样本计数剔除被留出社会。使用数值容差不超过 `1e-12`，所有类别概率为正且和为1。每组预期行数固定，并按社会ID排序。

## 必须失败的情况

来源哈希不一致、映射丧失双向唯一性、任何被纳入行仍含非法编码、任意社会多次作为测试、概率不归一/非正、训练折泄漏测试行、独立算法评分不一致、源行变更或协议更改均 fail closed。源数据更新一律要求新版本与重新预冻结，禁止补救性挑选有利模型。

## 限定成果

科研层级 `E1_REAL_OBSERVATIONAL_LOSO_BOUNDED`。留一社会不等于真正独立文化历史起源，更不等于实时外部预测、因果效应或政策评估。EA变量可能来自不同时间、不同文化观察者；SCCS按多样性筛选不构成独立随机抽样。语言谱系的模型校正需要外部可验证谱系或空间编码，当前不制造分组伪数据。R073和PESEN v0.1继续冻结，新增E2/E3=0。全部R系列研究完成后统一分类，最后熔炼。
