# R070 E1 所有 3×3 双群体配置的穷举迁移与全局单调性反例

日期：2026-10-16；**本协议先于任何 R070 3×3 全状态计算与测试结果冻结**。不是人类行为 E2。研究承接 R070 的 4×4 3 次迁移数学玩具，不因该单例成功而断言所有初态最终都满意、迁移必然增加局部相似度或宏观分隔。

## 有限全集与独立理论约束

棋盘 3×3（9 位置），精确 **2 个类型 A、2 个类型 B、5 个空格**，标签 A/B 只是数学抽象，不对应任何真实受保护人群。静态初态不同配置数严格为 C(9,2)·C(7,2)=756，由无重复组合枚举验证其双射完整性；不可只抽随机初态宣称穷举。

阈值五组 tau∈{0,0.25,0.5,0.75,1}，每个组合恰好 756 个原始配置，共 **3780 个独立确定性初态×参数情况**。移动规则必须直接导入已验证 [R070 Python 原模型](../research/R070/r070_schelling_spatial_migration.py) 的 run 函数，不可为有利结果修改邻接、迁移顺序、满意度或空邻位处理；每条最多执行 **40 次**迁移。

运行可能返回以下状态：STABLE_ALL_SATISFIED、STALLED_NO_SATISFYING_VACANCY、MAX_STEP_BUDGET。其中 STALLED 代表存在不满意者但无符合规则的合法迁居点，绝不可改为“空间稳定均衡”或暗中认定群体满意；MAX_STEP_BUDGET 不能称作已收敛。

## 事先定义输出

- 每个 tau 的三种状态次数、迁移次数总和/最大值、初态已有不满意者个数、终点依然不满意者个数、在初始/终点有定义的**四邻接占用边**的异类型占比的均值、最终异类型接触占比高于初始的案例数、终点拥有更多不满意者的案例数以及全局局部同类比例不升的案例数。
- 将每条轨迹的**一步异类型接触比例增加**独立计数。初态没有任何占用 cardinal 边或终态没有，指标为 null，不能把 null 当0或混入分母。遇到任何一步同类/异类代理数不守恒、初态枚举有重复、个体移动目标不满意、移动后版面格值非法，FAIL_CLOSED。
- 各 tau 最多一个**词典序最先**的纯合成反例棋盘（初态 board、tau、各期起终局部指标，不涉及真实人口位置）。必须与明确计数相对应；不能按最终研究方向挑选反例、过滤不可令人满意的情况。
- 明确对 tau=0 全部 756 配置 moves=0 的先验不变量；全部 tau 每个拥有 756 状态，恢复总数 3780。对于每条运行合成轨迹，所有 agent 类型与空置数始终是(2,2,5)。
- 实验设计只能证明极小规模**确定性规则系统**的条件性全状态结果，不能解释真实住房迁移、历史分隔、房地产市场或身份心理偏好。与 Schelling 1971 的出版理论及 Gambetta et al. (2023, DOI 10.1038/s41598-023-38519-6) 的迁移约束模拟相比，两者实现规则/规模不同；不得把本输出标为原作者的重复计算。
