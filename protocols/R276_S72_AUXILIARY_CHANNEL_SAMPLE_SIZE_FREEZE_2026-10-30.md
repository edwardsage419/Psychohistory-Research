## Frozen model and experiments
Maintain three equally likely true models in order A,B,C. Independently observe four Y~Bernoulli(q=1/4) and m independent auxiliary Z~Bernoulli(theta1) with m in the fixed integer grid 0,1,2,3,4,5,6,7,8. Y has the same joint distribution under all models and cancels in posterior ratios. No fitted parameters, no hyperparameter selection, no new candidate models. For every m enumerate all 2^m ordered binary Z strings, including zero-mass strings for C. The model likelihood for an ordered string with k successes is theta1^k*(1-theta1)^(m-k), using exact rational arithmetic and 0^0=1 for zero exponent. Equal model priors. MAP picks the first candidate in order A,B,C when likelihoods tie. For m=0 use empty string and all likelihoods 1.

## Frozen outputs and checks
For each m, report conditional confusion probabilities P(predicted model | true model), conditional correct probabilities, equal-prior macro accuracy, zero-mass source count and total ordered source count. Compare full ordered-string enumeration (R route) with independent binomial-count summation (B route). All conditional confusion rows must sum to one. Macro accuracy must be nondecreasing with m because the decision rule is Bayes-optimal under the fixed prior and an additional independent Z can be ignored. At m=0 macro accuracy must equal 1/3; at m=2 it must equal the original 11/16 with conditional accuracies A=1/2,B=9/16,C=1. For each m, calculate the exact probability that the MAP selection is wrong and the first m in the frozen grid whose macro accuracy reaches at least 9/10, or NONE. This 9/10 threshold is chosen before new scores. Report the full nine-point curve regardless of threshold crossing. Exact Fraction equality required, no floating tolerance.
