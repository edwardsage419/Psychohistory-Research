## Fixed source equation specification
Each arriving R or S type has prior payoff for A/B:
R: (a_R + r*nA, b_R + r*nB);
S: (a_S + s*nA, b_S + s*nB).
Each newcomer adopts one technology and cannot reverse earlier decisions. If utilities tie, assign either adoption with exact probability 1/2; otherwise choose strict higher private current payoff. R/S newcomers each independent with probability 1/2 unless finite-order conditioning is explicitly invoked. Baseline a_R=2,b_R=0,a_S=0,b_S=2,r=s=1; starting (nA,nB)=(0,0). d=nA−nB. R chooses A for d>−2, S chooses A for d>2, with ties at d=±2. At d≥3 all types must choose A permanently, and at d≤−3 all types must choose B permanently. **Do not declare d=±2 absorbing** because ties still random.

5. **Separate constructed inefficient potential case** r=1 for A, s for S cannot model different slopes across technologies using original Table 1 directly: original r/s are **agent-type-specific slopes shared by both A and B**. Explicitly add a **non-original asymmetrical-technology extension** for R: A payoff 2+nA, B payoff 2*nB; S: A payoff nA, B payoff 2+2*nB. Condition on first three R types => A gets three adoptions and is locally locked under no subsidy, even though if each technology had been independently developed with three adoptions, technology B would deliver higher payoff to both types (R:6 vs5; S:8 vs3). Distinguish these counterfactuals from aggregate lifetime realized welfare, which is not estimated.
