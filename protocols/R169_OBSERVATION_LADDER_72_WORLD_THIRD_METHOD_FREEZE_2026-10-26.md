O1: number of nodes in state 1 only.
O2: joint (number in state 1, discordant edge count).
O3: joint (number in state 1, discordant edge count, connected component count).
O4: complete labeled graph edges and opinion vector.

Within each initial stratum and each time, partition the six parameter controls by exact equality of observed distributions, report number of equivalence classes, unique controls, ambiguous controls and pairwise distinguishable control pairs out of 15. Aggregate across 12 strata. Include one exact rational total-variation witness for a pair with O1 equal and O4 different when available. Compare O1,O2,O3,O4 information monotonicity; if any coarser observation distinguishes controls that a finer observation cannot, FAIL.
