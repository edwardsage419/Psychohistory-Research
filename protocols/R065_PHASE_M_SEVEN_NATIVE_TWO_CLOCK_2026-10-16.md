# R065 Phase M：原作者七模型的两套状态重置时钟留人比较（研究前冻结）

日期：2026-10-16。依据 Phase L 完成后的下一门控，研究目的限于比较**状态重置时钟**的影响；不得根据 Phase M 结果修改实验协议或把样本内既有研究作为外部新证据。

## 1. 数据、参考与时钟固定

- 上游源码仓库 `arielevy8/obs-learning-fishing` 固定提交 `fd5f435b5368b69916e7acc6a9991aa5f46b3ddb`；`model_fitting/objectives.py` 原始 Git blob SHA1 `5e98133fa274ef2a112b24f6fdcd802d4f9d3eec`，`fit_utils.py` 原始 blob `6046f083a1181b10a7d991c8c9fd2e53c1f2b487`。
- 数据完全继承 Phase J 既定 24 人、每人 136 行正式实验试次及 1,327 次 `play`；所有源文件按各自 Git blob 字节哈希验证，processed CSV 和排序/筛选过程相互核查。不公开人级别行为或 ID。
- **时钟 A：作者原生时钟** `[23,45,67,89,111]`；源文件哈希验证后直接以作者未修改程序运行。
- **时钟 B：实验区块起点候选时钟** `[18,35,52,69,86,103,120]`，与已归档 Phase H/J 定义一致。为避免对其它机制修改，仅从精确哈希核验的 `objectives.py` 原文字节中，在内存里替换七个完全一致的重置判断表达式；如果命中次数不恰为七，则立即拒绝。作者源文件保持只读，适配器明确标为研究修改后的执行版本，不能称原作者未修改源码。 `fit_utils.py` 保持原样。
- 事先以所有模型在同一个作者时钟参数化执行路径与未修改作者原生函数进行固定参数零向量 NLL 全 24 人数值一致性测试；有一个模型失配即整体阻断。状态重置替代仅改变每个函数的重置日常量，其他代码保持字节相同。

## 2. 固定训练与预测比较

- 完全复用 Phase L 分层的两折（每折 12 人，分别高先/低先各 6 人），只使用 12 人训练参数、再对另一折 12 人预测。两折留出共有 1,327 次 play。
- 重新分别在时钟 A 与 B 下，对七个模型各做两折**共享训练参数**优化。两套时钟都采用相同 `L-BFGS-B`、两固定无约束参数起点、每维 [-8,8]、`maxiter=80`、`maxfun=900`、`ftol=1e-8`、`gtol=1e-5`。
- 只接受数值有限且 SciPy `success=True` 的优化候选；两起点皆失败则该模型/折标为 `UNRESOLVED`，总比较不报告七模型完整 PASS。不得根据试验结果重设起点、扩大 budget、改变时钟定义或选择折。
- 时钟 A 重算后的每模型两折 NLL/选择，必须与此前 [Phase L](../research/R065/R065_PHASE_L_NATIVE_HELDOUT_RESULTS.json) 的完整归档折数值在绝对误差 `1e-7` 内一致，否则整体 FAIL CLOSED，禁止比较时钟 B。
- 固定主要对比：`Δ = mean_NLL_B - mean_NLL_A`，**负值**说明候选时钟 B 在这次固定样本和研究拟合下预测损失较小。每模型记录两个折的各自 Δ，以及 1,327 次 play 的加权总体 Δ；七模型整体图表或名次只能作回顾性探索描述。
- 必须同时记录 A/B 各自的完整两折 NLL、优化状态、收敛起点与聚合调用数、审计 source pins、每个模型独立 Github Actions job ID，保持匿名。不得以模型复杂度或两套时钟优化时间不一致作为优劣结论。
- 源数据的 `observe` 历史仍是测试对象状态输入的一部分；测试人员的 `play` 从不参与该折模型训练参数的估计。此指标为内部留人条件性预测，并非前瞻完全独立研究。
