# 心理史学研究统一验收与结题标准 v1.0

制定日：2026-10-16。性质：今后各 R 编号的研究执行与报告验收规程。对在此规程以前完成的研究，只能作**事后证据审计**，严禁冒称原先已经按照本标准预注册。

## 一、单位、对象与结题范围

一个 R 编号对应一个明确的研究问题、一个可审计的交付范围、一份最终报告。内部多次测试/阶段属于实现证据，并不等同于多个已独立证实的研究结论。新数据、新机制或独立问题优先另立 R 编号；只有影响原主问题判读的关键反例继续留在原 R 下。

从此规程生效后的 R 项目，应在首个结果出现**之前**固定：问题、数据与合法使用界线、模型版本、判定指标、必要的对照、最小样本/有限试验范围、成功/失败条件与停止规则。对于已进行中的历史研究，必须标注 `RETROSPECTIVE_SCOPE_DECISION`，不得把事后范围缩减称为预先约定的成功关口。

## 二、研究验收必须覆盖的六项核验

| 编号 | 核验项目 | 满足条件 |
|---|---|---|
| A01 | 问题与范围 | 记录具体研究对象、条件与排除项；原主问题是否完全回答必须如实标注 |
| A02 | 证据来源 | 真实论文、代码、数据出处；版本、固定字节/hash 或永久标识；转载与权限边界 |
| A03 | 计算与可复现 | 可执行代码、离线/真实数据分开；实际已跑与未跑区分；固定环境和校验记录 |
| A04 | 反例与失败 | 关键负结果、样本限制、算法不收敛、重复不一致、缺失来源全部记录，禁止静默修改通过阈值 |
| A05 | 推断边界 | 合成测试/原始数据再运行/内部留出/外部独立验证四级严格区分；不能因单一更小损失断定机制因果 |
| A06 | 结题与移交 | 独立最终报告、证据汇总、未解决任务清单、GitHub 提交和最新主分支核验；不回填为成功 |

## 三、状态词与失败优先

对每项核验采用 `PASS`、`FAIL`、`OPEN`、`NOT_APPLICABLE_WITH_RATIONALE`；缺失信息归 `OPEN`，**FAIL 永远不自动转换为 PASS**。子研究有 FAIL 时，应写入最终报告的 `NEGATIVE_EVIDENCE`。

- `CLOSED_FULL`：事先确定的完整研究目标与强制门全部 PASS，且无阻断性 FAIL/OPEN。
- `CLOSED_BOUNDED`：限定研究包的材料、方法、真实证据及最终报告可验收，保留未完成原始广义目标、后续子试验 FAIL/OPEN 的明确清单。**此状态是行政与研究档案结题，不代表完整原始科学目标成功。**
- `BLOCKED`：限定交付包本身来源不可核验、运行结果无法解释或强制证据缺失；不得宣称结题。
- `ACTIVE`：仍然执行本 R 限定交付。

历史项目只能在当前真实证据之上采用 `CLOSED_BOUNDED`，并应额外说明哪些是事后范围决议、哪些失败从未解除。结题不停止未来新证据检验；如需重启，应另立版本化续研究及协议。

## 四、可移交证据级别

- E0：假设/计划，无研究验证。
- E1：合成数据测试，验证程序结构，不验证现实机制。
- E2：核验原始来源、真实数据及精确代码的可重复计算；内部训练/留出属于 E2，记清已使用同一个研究总体的事实。
- E3：预先确定评价方法、来自独立新研究总体/实验的新证据，并有来源可重复核验。仅拿原始数据中尚未用于拟合的折不属于 E3。

版本升级、科学发现或专属模型参数采纳必须有单独授权与明确证据门；文献模型运行通过不会自动更新 PESEN v0.1 或其它主模型。

## 五、工时与新模型拓展

研究结题以证据与范围一致性为准，而非阶段数量。原则上先取得一个可重放的**最小完整研究包**，再根据失败的科学重要性决定继续投入。若一个 R 已形成可引用、有边界的结果，新的多模型家族研究优先开立下一个 R，并在现有 R 的 BACKLOG 保存尚未验证问题；不得通过扩大某个 R 的范围无期限阻滞广泛学习不同模型。

每份结题报告至少包括：研究问题、来源与版本、方法、已实跑结果、反例、不能声称的结论、A01–A06 状态、最终归档状态、后续研究挂钩，以及可核验 GitHub URL/提交。
