## Individual original-row schema frozen prior to any behavior calculation

First row in each sheet is the author header; remaining rows are exactly four per focus actor. For each four-row block: rows 0,1 are both players from session 1; rows 2,3 both players from session 2. These four rows are ONE focal participant repeated with partner rows, not four independent people.

Type1 focal actor has own actual contributions from block row 0 (session 1 Player1) and block row 3 (session 2 Player2). Type2 focal actor uses row 1 (session 1 Player2) and row 2 (session 2 Player1). Never count partner action rows as second independent original actors for that block. Column A contains author participant identity metadata; require nonempty first row of each 4-row block. If no identity or conflicting identity meaning arises, stop entire source metric before publishing. Do not print actor IDs or hashed IDs, pair identifiers, raw individual contribution history or any original Excel body.

Contribution columns are C..V (rounds1..20) for BOTH threshold sessions. Linear first session has C..X (rounds1..22), second session C..W (rounds1..21); spare linear column X in second session is NOT a missing 22nd round. All own actions must be real numeric finite nonnegative and not booleans. Any missing/invalid/ambiguous personal action -> fail closed for that whole game; no deletion or imputation. Originator source documentation says no missing-data codes. Do not infer absolute endowments or classify percent-of-endowment, since role-specific endowment/payoffs not yet independently extracted.

## Primary and secondary fixed estimates

For each game (2) × treatment (5) × session (2), exactly 20 main descriptive result units. With N original focal actors per treatment, each contributes one observed first and last contribution. Compute equal-actor mean first, mean last, mean difference last-minus-first. Also count n increase, n decrease, n zero difference summing to N; report per-round mean contribution across N actors (length 20 for threshold, 22 / 21 for linear); report each Type1 / Type2 role subgroup for negative case sensitivity, but never filter or reorder based on outcome. Report whether first-to-last mean difference sign is consistent across session1 and session2 of same game+treatment. Session role changes and partner rematching mean this is NOT a randomized independent cohort replication. Across treatments contribution amount is raw experiment units and may differ by endowment, so DO NOT rank treatments by absolute averages as welfare or efficiency, and do not compare numerical level across separate games as causal.

Competing sign-level mechanisms: M0 no directional within-session aggregate change, M1 positive accumulation of cooperation, M2 negative erosion; negative, null and direction reversals mandatory. No p-values or participant-level independence claims without original exact pairing cluster and randomized treatment design; do not claim cause of any pattern, institutions chosen, or historical evolution. Surveys excluded to avoid after-decision information leakage.
