## Three fixed prediction models and cross-person heldout

For each person i, round t in 2..10, need `decision(i,t)` and `decision(i,t-1)` both legal observed binary source values. Same sample of test participant-rounds for all models. **M0** mean *other persons j≠i* with **same original source `visibility` value** and round t, counting only legal observed decisions; no target participant's current decision, entire participant i data excluded from any M0 group average. This averages across original 2015 inequality conditions and distinct original 80 sessions because such identifiers absent from secondary CSV; it's a coarse across-session baseline **not target's own original same-session peer mean**. **M1** previous observed `decision(i,t-1)` (0 or1), no hyperparameter, no target t leakage. **M2** fixed half-blend `(M0+M1)/2`, strictly pre-frozen. All predictions 0..1; binary Brier score `(p − decision_i_t)^2`. Pooled and by source `visibility=0` vs `visibility=1`, per t=2..10 report legitimate targets, source full-ID person M1 over M0 positive/negative/ties, non-scored IDs, full source observed/missing/invalid action counts; every denominator explicit. Report 1462 source ID context but score only pair-valid rounds.
