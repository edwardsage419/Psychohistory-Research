# MKT190 Git-based decision history: mutable references and retention failure
Date: 2026-11-01 UTC. Track: market. Target: (market,Git,Git-2.47.3,decision-log-branch-rewrite-and-garbage-collection). Status: COMPLETE_BOUNDED. Baseline main: 81bf2ef24278a2a11d6ae707a77f204cd8fb4825.

## English original sources and evidence levels
Official Git manual https://git-scm.com/docs/gitdatamodel distinguishes immutable content-addressed objects from mutable refs and expiring reflogs. Official https://git-scm.com/docs/git-reflog describes local ref update history and expiration. Official https://git-scm.com/docs/git-gc describes removal of unreachable objects. Git is an open-source general-purpose version control mechanism, evaluated here as a candidate component for decision journals, not as an end-user life-planning product. No third-party product's implementation was executed. Prior MKT189 Reflect OS self-reported outcome and independent adjudication work was read to avoid repeating its outcome-scoring experiment.

## Inputs, states, algorithm, goal, feedback, privacy and price
Synthetic input: D1 decision identifier, prescore forecast probability 0.8, later SELF_REPORTED_SUCCESS outcome. States: Git blob/tree/commit IDs, main ref, local reflog, reachable or unreachable objects. Mechanism: content-addressed Git objects, commit parent chain, mutable branch refs, local reflog, garbage collection. Goal of candidate use: preserve original forecast and correction history for later adjudication. Git itself supplies no outcome verification, calibration, causal inference, confidence correction, multiobjective utility, or automated feedback policy. Explainability is source-level via git log/show/rev-list; audit completeness and third-party witnessing require additional controls. Git is free open source for local use; optional hosting has separate terms, not used. A local repository avoids automatic cloud transfer but historic sensitive text can persist in older commits; deletion and retention governance conflict with indefinite evidence retention. Git author dates and locally configured author identities are not independent time or identity proof.

## Native local experiment
Executed actual Git 2.47.3 via Python 3 standard library in a temporary local repository, no network, no personal information. Archived reproducible program: research/market/mkt190_git_history_rewrite_probe_20261101.py.
1. Commit a synthetic prescore D1 JSON. Commit a later synthetic self-reported outcome.
2. Reset main to the earlier forecast commit. The outcome commit immediately disappears from main history while its object remains directly accessible and in the local reflog.
3. Explicitly expire all reflog entries and force git gc --prune=now --aggressive in the disposable repository. The now-unreachable outcome object is no longer accessible.
Observed final test PASS. Example run forecast SHA 05c1aab9ebf0a1ea9a435ac8b41dc54dc19aeea9, outcome SHA 3159e588173606cd6697594395c1b2d94da3fd39; IDs vary by commit metadata. Before forced cleanup outcome in main=false, in reflog=true, object accessible=true; after cleanup object exists=false. Forced expiry is intentionally stronger than normal default Git retention. No real user's repository was touched.

## Interpretation and falsification
Content hash protects the bytes of a retained object; it does not force a mutable branch to retain every prior event or make an event independently witnessed. A successful local git log is not evidence of complete original decision history. A hash or signed commit does not verify that a self-reported outcome is true. Candidate controls: separate forecast and outcome events, immutable external checkpoint held by independent witness, missing-event detection, correction provenance, explicit private-data retention/deletion policy, opt-in encrypted local storage, and never automatic high-impact decisions. No Git hosting, CI, paid service or external signing was used. This experiment establishes a native Git engineering counterexample only, not empirical decision quality or vendor security. E1 engineering evidence, no human E2 and no historical E3.
