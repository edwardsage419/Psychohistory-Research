## Reproducible finite experiment
Native Python 3 standard-library `sqlite3` script `research/market/mkt157_sqlite_snapshot_20261031.py` executed locally: 18/18 assertions PASS. Two fictional histories use the pinned delete-then-insert semantics. A originally had (habit=1,date=100,value=2); B originally had (habit=1,date=200,value=2). Both later end at exactly (id=2,habit=1,date=100,value=0,notes=''), with the same SQLite `sqlite_sequence=2`. Their final logical table rows and native SQLite logical backup projections agree; their earlier event dates differ. Thus even the row ID and final logical database state do not identify earlier entry content. The local test uses `sqlite3.Connection.backup` as a logical snapshot, while actual Loop uses file copying; no raw file byte-identity, forensic erasure, concurrency safety, WAL correctness or Android restore fidelity is claimed. An additional finite list rotation assertion shows `keep=5` can yield 6 after a new copy in the pinned operation order.
