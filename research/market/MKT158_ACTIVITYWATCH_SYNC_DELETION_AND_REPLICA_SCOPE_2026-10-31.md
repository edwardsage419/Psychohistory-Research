## Mechanism inventory
Input: app/window/browser events and optional watcher data. State: per-device owner buckets, timestamp/duration/data event records, staging sync database and destination imported buckets. Algorithm: owner writes own sync files, external folder transport, remote bucket import, cursor-limited reconciliation and optional exact-tuple dedupe. Feedback: time/activity charts, categories and multi-device views, not verified decision outcome improvement. Explanations: source and public docs; no tested user explanation/appeal interface. Privacy: default local, cross-device copies depend on transport, all buckets synced by default, deletion propagation absent. Cost: free core; optional $5/month support and potentially paid third-party transport are outside zero-cost project scope. Validation: official docs and upstream README plus bounded synthetic experiment, no real sync process or user data.
