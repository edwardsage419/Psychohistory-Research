## 1. 人工实验与严格可识别边界

本轮独立于 MKT133 的群组抽样例，考察结果本身影响反馈被观察的概率，且该概率未知。固定可见的联合概率质量：P(S=1,Y=1)=1/16，P(S=1,Y=0)=3/16，P(S=0)=3/4。可见反馈中阳性比例 q=1/4，总体被观察比例=1/4。S 表示结果被观察，Y 为二元结果。这里的概率来自人工设定的生成世界，并非个人真实资料。

构造三个人工世界，其全部可见联合分布完全相同：

| 世界 | 总体 P(Y=1) | P(S=1|Y=1) | P(S=1|Y=0) |
| --- | ---: | ---: | ---: |
| 结果无关入样 | 1/4 | 1/4 | 1/4 |
| 阴性更易入样 | 1/2 | 1/8 | 3/8 |
| 阳性更易入样 | 1/10 | 5/8 | 5/24 |

因此仅凭相同可见数据，真实总体阳性率可为10%、25%或50%。即使已知总入样率，真实目标仍不可点识别。只有物理入样概率在(0,1]的限制时，P(Y=1)∈[1/16,13/16]；若另要求正入样率比 r=P(S=1|Y=1)/P(S=1|Y=0) 在[1/Γ,Γ]，则给定可见 q=1/4 有：

P(Y=1) = q/[r(1-q)+q]，与物理可行界取交集。

| 预先假设的 Γ | 精确可行区间 | 使用阈值2/5的保守决策 |
| --- | --- | --- |
| 1 | [1/4,1/4] | NEGATIVE_ROBUST |
| 2 | [1/7,2/5] | ABSTAIN |
| 3 | [1/10,1/2] | ABSTAIN |

Γ=3、阈值3/5时，由于上界仅1/2，可稳健判断低于阈值。Γ是分析者提供的假设强度，真实系统不能自动认为 Γ≤3。阈值仅用于人工示范，不代表个人效用权重或现实决策规则。对于恰等于阈值的上界，程序保守弃权，避免边界自动断言。

## 2. Beeminder API 深读：更正、重试与历史状态版本

2026-10-29 UTC 检查英文官方 API、隐私帮助、服务条款及价格页面，仅公开资料审查，无账户、token、收费请求或真实数据。

* 输入：手动或自动提交 goal datapoint，包含 timestamp/daystamp、value、comment；目标含 goaldate、goalval、rate、runits、pledge、safebuf、road、losedate 等。状态以目标红线和安全缓冲表示，偏离可能触发实际财务承诺。接口支持读、写、编辑历史点和目标设置。
* 核心技术细节：POST datapoint 可带 requestid；相同 requestid 且数据相同视为重复，相同 requestid 且内容不同会更新既有记录。这是幂等重试与历史修订共用的 upsert 语义。datapoint 的 timestamp/daystamp 与 updated_at 分开，按 updated_at 获取最近更新的记录可能返回时间戳很早的修订点。用户层 updated_at 可供增量同步，不能用“最近更新”推断“最近发生”。
* 解释与反馈：road/fullroad、safebuf、safebump、losedate 和 pledge 暴露目标进度及后果。官方 API 文档对 currate 的左右极限定义仍注明在2026-09-29调查中，需保留该语义不确定性；不能把此字段当成已验证的精确即时导数。API 描述未提供长期人生效用模型、随机化试验或可复算行为改善效应。
* 隐私权限：API Goal 中 secret 与 datapublic 分开控制；官方帮助说明新目标默认公开图表但隐藏具体 datapoint 值，用户可设为完全私有。官方服务条款允许必要的员工、承包商及供应商处理个人资料。API 认证令牌必须视为敏感凭据，本轮没有访问。
* 费用：官方 premium 页面当前列 Core $0/月、Infinibee $8/月、Bee Plus $16/月、Beemium $81/月。基础方案虽为零月费，目标失约承诺可能扣款，不能视为绝对零财务风险。
* 局限：接口文档支持数据字段与重试语义，隐私和商业效果仍为官方说明。无产品账号实际测试、无独立安全审计、无真人效果实验。
