# B 科学证据审计：R140 制度效力、严格等价与推断边界

日期：2026-10-25。目标为 R140 原研究的最新有限机制结论。审计依据为先前冻结的第三方法协议、独立 Python 与 Node 逐行精确重算、GitHub 原 R140 一手研究报告。此审计与 R140 主线研究报告分开归档。

## 审计对象与实际结果

1. **计算完整性**：128制度、1136可行档案、4584可行单侧偏离均与原归档一致；128制度的完整档案、每人净收益和NE标签通过两语言逐行对照。6类签名、2272对严格等价制度均经精确计数。内部程序性独立复核通过。
2. **规则实际作用**：固定其他六个轴，仅翻转一个规则轴的64对制度，严格博弈不变的配对数为 boundary 28、position 32、choice 0、aggregation 60、information 60、fee 60、scope 60。information和fee各64对的纯NE全部相同，其中各有4对改变私人净收益。单凭NE行动无法判断征费是否改变私人支付，也不能把规则名词出现等同于制度实际起效。
3. **均衡选择与基线**：无规则三开采者基线NE(2,2,2)，G12，资源最优G16。124个制度的全部纯NE均达到各自可行资源最优；其余4个制度均保留该基线无效率。存在资源最优均衡只是静态数学结论，未提供动态收敛、真实实施成本、公平性或选择机制。
4. **负例与敏感性**：已执行冻结的有效征费取消、无管理人误征费和删去可行偏离边三类错误控制；两语言均对原模型的完整档案与NE一致。四个基线无效率制度作为模型反例完整保留，没有因为124个有效率制度而删去。
5. **来源与外推**：Ostrom 2011 是 IAD 分类与分析框架来源；三名合成人、收入 `e_i(8-E)`、收费2、128配置来自项目自建。不能写成 Ostrom 原作者数值实验的独立复现。制度的严格数学等价不能推出真实世界制度原因不可识别的普遍定理；此处只能给出一个明确的反例。

## 后续验证缺口

若以后要提出真实制度有效性，必须先有规则实施状态、管理人资格、个体支付与罚款、行动可行约束及真实行动的独立观察，再冻结识别与评价设计；不能直接把128个人工制度当作128个真实制度实验。下一轮主线优先继续既定 R141 及后续 R 队列的独立审计。
