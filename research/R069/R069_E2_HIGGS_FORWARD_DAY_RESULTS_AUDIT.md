# R069 真人线上传播行为：严格向前日预测与负证据审计

日期：2026-10-16。层级：`E2`，同一公开原始事件集的**跨日期条件预测**；不属于独立 `E3` 队列，也不属于 Watts/IC 的真实因果机制拟合。

## 1. 数据源、已成立的独立来源核验

(2013), *Scientific Reports* 3:2980，DOI `10.1038/srep02980`。活动 gzip `higgs-activity_time.txt.gz` 官方 SHA256（研究计算）：`901b199716a23b0fc0371705e3ae9941b5c9493277aec65456abc4988674ad79`，压缩字节 4,169,461；真实 2012-07-01 至 07-07 期间的 563,069 条事件：RT 354,930、MT 171,237、RE 36,902。

之前真正执行 [源审计 run 38876285461](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/38876285461)（18 个测试 PASS）、[逐边源 parity run 38876563448](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/38876563448)（13 个测试 PASS），后者精确证明官网的 **328,132 条**有向 RT 汇总边就是**同一批 354,930 次 RT 活动的聚合**，而**不是外生的、事件发生前已经存在的关注网络**。本轮因此完全**不读取汇总 RT 图**作预测特征。

## 2. 先冻结的研究题目、风险集与训练窗口

[独立预测协议](../../protocols/R069_E2_HIGGS_FORWARD_DAY_RT_2026-10-16.md) 于首次真实预测损失计算前 commit `730ce9639c86f08ca772ebd2b7fd3ce6844b487c` 提交。任务为**二元行为**：当日 00:00 前曾发起 RT、MT 或 RE 的历史可见账户，是否会在下一个 UTC 自然日再次发起 RT。没有历史活动的账户明确不在风险集中，不能用全周期见过的全部账户作为历史风险集。

固定 2012-07-02、03 两日作为最初训练目标窗口；留出 2012-07-04、05、06、07 四个后续 UTC 日，逐日滚动加入**已结束**的训练日。仅在 `t<当天00:00` 的记录形成特征：

- 昨日是否有 RT、昨日是否有任意活动；
- 历史活动数 `1 / 2–4 / ≥5` 的三个固定分箱；
- 该账户**历史互动记录**中的被互动对象，有没有在昨日前一整日发起过 RT（布尔代理）。该对象不一定为真实可见的消息来源，之前的互动并非有效关注关系，更不是观察到传播暴露。

比较的四类预测：训练窗口总阳性率（Beta 1,1 平滑）；上一日训练阳性率；历史活动三特征分箱；加上历史互动目标代理后同样分箱。分箱预测均按训练总体阳性率给 `κ=100` 伪计数收缩。**没有事后变更参数网格、掺入预测当日结果作特征、按损失筛选结果或假定 763,846 账户日独立**。

该观测样本的风险集随着消息爆发剧烈变化。7 月 4 日大批 RT 参与者在历史活动窗完全不可识别，这表明对**事件首次行为**的外推覆盖率严重受限。观测风险集日等权的全局总体 RT 率虽最小，但此结果不代表不存在微观扩散或模仿，而且从日级图形直观看，突然扩散的外部新闻冲击比常数风险更难被简单历史特征描述。

本研究中纯历史个人活动模型的四天平均对数损失比全局模型大 `0.0084315` nats；加入历史互动对象代理后比个人活动模型进一步增大 `0.0011130` nats（不是改善）。此统计只是一个冻结简化特征/收缩参数、同一 2012 新闻事件中的样本外预测对照，并不等于对社会网络影响参数的显著性检验。

## 4. 机制识别限制、来源保密及可信度

- 先前的 SNAP 源为 `A retweets B`，并无推文消息根源 ID、原始内容/发帖前暴露的时间、未发生 RT 的完整机会、全时段有日期的关注关系快照。全周期 RT 汇总图由目标变量生成，已严格排除，但这仍不创造真正的暴露测量。
- `peer proxy` 只是“历史向 B 互动、B 昨天 RT”，可能反映同一话题兴趣和账户活跃度，不能视为 B 让 A 在今天 RT，也不能定义 IC 单次边传播成功概率或 Watts 阈值。
- 训练窗口最初只有两日，测试四日、单一高度爆发的话题和数十万相关账户日；不能把重复账户日当独立抽样，亦没有可靠日期级不确定性区间。需要多个独立话题/长观察期验证后才能升级 E3。
- 账户风险集只覆盖预先出现过的互动发起者，不能预测首次出现账户，不包含全平台接触到新闻但没有行动的人。
- 对数据出版原件只发布摘要、文件 SHA 和代码，不发布 SNAP 账户 ID、活动边、事件序列、原始 gzip；公开可获取不等于自动授权商业再分发。
