## 2. 与第八、第九阶段一致的模型设置

模型仍是作者 Model 3：复制最近一次观察动作；当最近动作不可用或被清空时，两条船等概率选择。其余行为使用作者原始 Softmax，评分为 `−log(p_actual+1e−10)`。

两套规则仅状态重置日不同：

* 作者公开源码：23、45、67、89、111。
* 区块边界候选：18、35、52、69、86、103、120。

对每一种规则分别提取 24 个人的 MATCH、MISMATCH、UNIFORM 充分计数，再以完全相同的目标函数、β 范围 [0,30] 和优化方法独立拟合；进行 24 折留整人评分，每次只用其他 23 人的数据拟合 β。总 NLL 除以全部 1,327 次正式 `play`，等价于按试次数加权的跨参与者评分；不是简单每人等权损失平均。

## 3. 原始实验数据上的聚合结果

| 指标 | 作者规则 | 区块边界规则 |
|---|---:|---:|
| 原始实验参与者 | 24（12 高先、12 低先） | 相同 24 |
| `play` 次数 | 1,327 | 1,327 |
| MATCH（复制可用的最近示范） | 453 | 487 |
| MISMATCH（有可用示范但没复制） | 275 | 303 |
| UNIFORM（最近示范缺失或不可用） | 599 | 537 |
| 固定 β=5，平均 NLL | 1.35273846 | 1.42616817 |
| 全样本最佳 β | 0.499121 | 0.474531 |
| 全样本拟合平均 NLL | **0.67658111** | 0.67685034 |
| 24 折留整人 NLL | **0.67843771** | 0.67867746 |

**留人评分的差值（候选区块规则 − 作者规则）= +0.00023975 NLL/选择**，极小。以整名参与者的留出总 NLL 对比，作者规则在 13 人上较低，区块规则在 11 人上较低，无平局。这里没有依研究方案外的显著性检验、重抽样置信区间或全人口效应估计。

对照前一阶段十份便利原始文件的 542 次 `play`：两套规则留人损失为 0.68635134 与 0.69086496，平均差约 +0.00451。第九阶段的结果在本次合格样本内明显缩小，支持的谨慎表述为：**模型比较的方向和幅度具有样本与拟合参数敏感性，现有证据不支持任何一套重置规则有稳定的优势**。不能把两批数据合并推断；本阶段 24 人由作者数据筛选，仍然属于同一实验而非独立复现。

## 4. 两种代码途径的独立数值交叉验证

本阶段在 GitHub 连接器执行环境内从 24 个真实原始人类实验文件构建 Model 3 逐人充分计数，再运行与 Model 3 源码语义一致的 JS Softmax/优化。此处的“真实”是指真实作者公开原始 `CSV` 输入，**不是作者原始 Python/Scipy 模型程序已经执行**。

另在当前 Python 容器中，以同一批临时充分计数执行 SciPy `minimize_scalar`，独立求得两套 β、平均全样本 NLL、24 折留人 NLL，并通过连接器 JS 代码独立重算核对。两者 β 的差异约 10^-8 至 10^-7，留人损失公差 **1e−8** 内通过。原始逐人 CSV 未从连接器转存至本地容器。

[可执行本地复现程序](r065_phase_j_screened_replay.py)要求用户提供固定作者处理 CSV 和 24 份原始文件。它独立重建同一批受试者的筛选、按源 Git SHA1 验证、训练其余 23 人、完成两规则 Model 3 对照，并与归档 JSON 的结果逐项核对；完整来源缺失则失败关闭。

[十项人工样本测试](test_r065_phase_j_screened_replay.py)已在 Python 容器内 **10 项全部 PASS、0 FAIL**，包括选择顺序确定性、反序输入不变、准确率/理解检查排除、错误日期/分组拒绝、文件哈希清单拒绝及结果不一致拒绝。上传的两份 Python 文件通过 Git blob 哈希核对与本地运行版本相同。注意测试所检验的是来源筛选和门控逻辑：**本地处理 CSV + 24 份原始文件的全数据重放尚未成功执行**。
