## 2. 固定来源和明确的问题

本文为 Levy、Roberts-Gaal、Cushman（CogSci 2025）`No Evidence for Cost-Benefit Arbitration Between Social Learning Strategies` 的**回顾性二次研究**。作者原仓库 `arielevy8/obs-learning-fishing` 的处理后 CSV `data/processed/unified_data_2025-01-16_00.csv`，固定 Git blob SHA1：

`01bf211468abe093618dfa5e5c39e883230c9c03`

原作者 `analysis.R` 固定 Git blob SHA1 `125a7d380218cb9a3ba62aaf340fd7ebf2744e5b`。原作者脚本在第 144 至 145 行明确单独提取 `critical == 1`，在第 187 至 190 行对关键试次 `accurate` 按收益条件建立混合逻辑模型。其设计为 8 个实验块，每个块内关键选择发生在前三次观察后，第三种实际选择对目标推断和直接模仿产生不同预测。

本轮通过 GitHub 连接器获取固定 blob 的 4,427,523 个 ASCII 字节，重新计算 `SHA1("blob " + byte_count + NUL + bytes)`，结果与预定 blob 精确一致。独立 CSV 解析得 16,103 行和 40 列，各必填字段无缺失。这里**实现了连接器执行环境内的固定原始处理文件哈希重算**；本轮本地容器没有获得同一完整 CSV 文件副本，不能写作“本地 Python 原始数据端到端重跑”。
