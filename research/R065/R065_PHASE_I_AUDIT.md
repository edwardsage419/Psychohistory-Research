# R065 Phase I — Model 3 参数 β 稳健性及留人交叉验证

日期：2026-10-16。性质：**针对 Phase H 已观察结果的事后参数敏感性研究**。在本轮新分数产生之前固定 [Phase I 比较协议](../../protocols/R065_PHASE_I_MODEL3_BETA_PROFILE_2026-10-16.md)，GitHub 提交 `cba034749c60fcee57b125c97315a670b77a2bc9`。不属于独立前瞻验证、七模型拟合或者心理史学原创模型参数晋升。

## 固定输入及作者目标函数

仍使用 Phase H 已固定的十份非随机原作者逐人原始 CSV，固定提交 `fd5f435b5368b69916e7acc6a9991aa5f46b3ddb`。通过 GitHub 连接器再次读取十份文件，校验每份 Git blob 与 Phase H 的清单一致。取 `phase=experimental`、每人 136 天，仅对共 542 次 `play` 选择评分；保留 Model 3 `observe` 记录最近观察行动且 `play` 不更新状态的定义。

源代码：`model_fitting/objectives.py` Git blob `5e98133fa274ef2a112b24f6fdcd802d4f9d3eec`；`model_fitting/fit_utils.py` Git blob `6046f083a1181b10a7d991c8c9fd2e53c1f2b487`。

每次 `play` 严格归于三类：最近观察到可用并选中该动作 MATCH；最近观察到可用但选了另一动作 MISMATCH；最近观察动作不存在或不可用 UNIFORM。

| 重置方案 | MATCH | MISMATCH | UNIFORM | 共计 |
|---|---:|---:|---:|---:|
| 作者 [23,45,67,89,111] | 182 | 120 | 240 | 542 |
| 实验块边界 [18,35,52,69,86,103,120] | 188 | 135 | 219 | 542 |

这三个聚合计数对给定 β 的原 Model 3 损失是充分统计量。以源码 `-log(p+1e-10)` 定义，MATCH 概率 `1/(1+exp(-β))`，MISMATCH 概率 `1/(1+exp(β))`，UNIFORM 概率 `0.5`。两种重置方案使用**相同的预测和损失函数**。

## 结果

| 情况（542 个 play 等权） | 作者重置 | 区块边界重置 |
|---|---:|---:|
| β=0（全部预测 0.5）平均 NLL | 0.69314718 | 0.69314718 |
| β=0.5 平均 NLL | 0.68178334 | 0.68713302 |
| β=1 平均 NLL | 0.70287888 | 0.71583535 |
| β=2 平均 NLL | 0.82045679 | 0.85386897 |
| β=5 平均 NLL（Phase H） | 1.41768147 | 1.52946179 |
| 同批全样本最佳 β | **0.41651496** | **0.33116721** |
| 最优 β 对应的全样本平均 NLL | **0.68132114** | **0.68508810** |
| **留出整名参与者的十折平均 NLL** | **0.68635134** | **0.69086496** |

取值区间 β∈[0,30]，采用固定迭代的有界数值最优化；同步计算忽略源码极微小 `1e-10` 修正时的解析最优值 `clip(log(MATCH/MISMATCH),0,30)` 做独立检查。全样本最优 β 并不能视为对外部人员的泛化能力评估。

**留人评估**：逐个从十人中留出一人，只在另外九人对应的计数上拟合 β，然后对整名被留出者的所有 `play` 评分；十折损失加总后除以 542。作者方案十折 β 区间约 [0.2643,0.5088]，边界方案约 [0.1711,0.4229]。这保证分数没有在同一折训练测试中泄漏被试行为，但十人并非随机抽样，不存在独立新队列。

两方案的留人差值（边界－作者）为约 **+0.00451 NLL/选择**，显著小于 β=5 时的 +0.11178。因此 Phase H 的效应幅度对任意固定 β 非常敏感；源码时钟对齐不保证有预测增益，修正时间轴的模型也不必然低效。

## 数值纠错与可复现范围

为比较 β 从 0 到 30 的完整区间，本阶段发现 Phase H 本地等价程序在极端高 β 时以 `1−p_match` 计算 MISMATCH，存在浮点消减精度问题。现将源等价程序修正为独立使用 Softmax 的指数项 `exp(−β)/(1+exp(−β))`，并新增 β=30 的极小概率测试。Phase H 先前固定 β=5 的四舍五入级差异不改变定性结论。

* [固定来源十份原始文件的汇总结果](R065_PHASE_I_RESULTS.json)：包括三个选择分类计数、两套拟合 β、完整留人分数和上游文件 Git blob 哈希。仅公开汇总数据，无个人试次。
* [Python 计算及精确原始文件 SHA 门控](r065_phase_i_beta_profile.py)：支持从已归档的匿名总计重算全样本 β 剖面，以及取得十份固定原始文件时额外重算逐人留出检验。
