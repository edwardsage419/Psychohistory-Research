## 2. 固定的四个预测模型

所有模型使用相同的 1,808 次关键选择，以参与者为留出单位，对作者二元 `copied` 字段计算概率。

| 模型 | 训练集用于估算模仿概率的信息 |
|---|---|
| M0 | 所有参与者训练记录的统一模仿概率 |
| M1 | 按 high/low 收益级别分别估算 |
| M2 | 按第 1 至第 8 关键试次实验块分别估算 |
| M3 | 按实验块与收益级别交叉组合分别估算 |

每个统计单元的平滑均值均为 `(训练成功次数+4)/(训练记录数+8)`。四个模型不做结果后超参数搜索，所有被评分者的**整个人 8 次结局**从训练单元计数移除。对数损失与 Brier 先按人平均，再对 226 人等权汇总，数值越低越好。

这里是概率基线模型，未编码示范者隐含信念、行动价值或强化学习更新，因此不能凭统计分数识别模仿与目标推断心理机制。

## 3. 已纠正的一次计算实现问题

第一次内部草算仅从训练单元减去当前测试行，导致训练率仍含同一留出参与者的其他关键选择。此为**数据泄漏的错误算法**，该版成绩已弃用，从未保存为 Phase D 正式实证 JSON。发现后按完整参与者计数逐单元扣除，重新计算全部评分与 Bootstrap。

修正后 M0 对数损失 `0.6648095962336775`，M1 `0.6651537585910515`，与此前 R065 Phase A 已独立发布的同口径关键试次 LOSO 数值一致，差异小于 `1e-10`，作为回归校验。新增 Python 代码 `r065_phase_d_loso.py` 与人工构造数据测试 `test_r065_phase_d_loso.py`，专门针对泄漏和完整个体排除实行 fail-closed 约束。

## 4. 真实数据四模型得分

| 模型 | 受试者平均 Log loss | 受试者平均 Brier |
|---|---:|---:|
| M0 | 0.664809596 | 0.235934555 |
| M1 | 0.665153759 | 0.236096921 |
| M2 | **0.661562755** | **0.234359476** |
| M3 | 0.663022395 | 0.235036474 |

同一名参与者在四模型中贡献相同数量的已评分试次。M2 在两种损失中样本平均数最好，不能据此单独认定具有独立样本上的优越性。

关键对照（前者减后者，负数为前者较好）：

| 对照 | 平均 Log loss 差 | 受试者 Bootstrap 95% 区间 |
|---|---:|---|
| M1 − M0 | +0.00034416 | [+0.00013231, +0.00056629] |
| M2 − M0 | −0.00324684 | [−0.00824466, +0.00169014] |
| M3 − M2 | +0.00145964 | [−0.00247556, +0.00541067] |
| M3 − M1 | −0.00213136 | [−0.00809271, +0.00383464] |
| M2 − M1 | −0.00359100 | [−0.00859361, +0.00132577] |

Brier 差值及区间另见 JSON。20,000 次参与者等权配对自助采样，伪随机种子 `20261016`，重抽样单位为参与者；重抽样内部**不重新拟合训练统计量**，区间条件于已给出的交叉验证预测，不能当作学习算法跨新样本的完整抽样不确定性。

M2 相对 M0 的平均改善约 0.00325，区间跨越零。增加实验块×收益交互的 M3 相比 M2 略差，差异区间也跨零。单独的收益分层 M1 相比统一 M0 在这一已见样本上表现略差。

**结论：本数据提示时间位置可能较收益大小更能预测模仿概率，尚不支持可靠的模型晋升或对认知机制的确定归因。**
