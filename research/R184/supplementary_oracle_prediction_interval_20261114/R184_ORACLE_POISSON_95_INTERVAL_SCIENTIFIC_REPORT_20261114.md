## 一、结论和防重复边界

对 R184 的 **45 种互异人工边际计数分布**，假定泊松预测者**已知**每种人工分布真实均值 `mu = n*p`，依照同一个 Poisson(mu) 的 2.5% 和 97.5% 分位点形成名义 95% 的未来独立计数区间。以原始人工生成分布计算，**14/45 个区间覆盖率低于 95%**；最差 `131830/177147 = 74.4184208595%`。全部 45 个同源真分布的百分位对照区间覆盖率均至少为 95%，说明数值差异来源于分布假设，而非离散分位区间不可能精确等于 95% 的普遍限制。

原始 R184 于 2026-10-21 已完成 45 世界的 Poisson 工作似然、均值、方差、零计数概率、预测计数 MSE 和对数损失，2026-10-26 又完成 270 组零事件 Brier 研究。本增量仅审查**整段预测区间覆盖率**；不重复上述评分，不修改冻结协议或原 `CLOSED_BOUNDED_E1_ARTIFICIAL_EXACT_POISSON_GLM` 验收。R183 的 Fisher Type I 误差和后续科学收尾由其他线程承担，也不在本研究范围内。

## 四、分位点和精确算术

对 `mu=n*p`，令 Poisson 累积分布 `F_mu(k) = exp(-mu)*sum_{j=0}^k mu^j/j!`。定义

`L=min{k≥0: F_mu(k)≥1/40}`，`U=min{k≥0: F_mu(k)≥39/40}`。

虽然 `exp(-mu)` 一般是超越数，分位点判断可以**用严格有理数上下界**完成。在 `m=56` 处固定 `S_m=sum_{j=0}^m mu^j/j!`，由于 mu≤6 和 m+2=58，严格成立

`S_m ≤ exp(mu) ≤ S_m + [mu^(m+1)/(m+1)!]/[1-mu/(m+2)]`。

所以 `F_mu(k)` 分别由 `sum_{j=0}^k mu^j/j!` 除以上述指数的上下界给出精确的有理数区间；每个0.025或0.975分位点均已严格证实本点达到阈值而前一点未达到，不需要浮点容差。对同一泊松模型，根据上述区间界计算的理论覆盖率下界均≥0.95。

真实覆盖率使用原计数PMF的 **Fraction 完整求和**：

`C_true=Σ_{k=L}^U P_source(Y=k)`。

另以同一**真来源PMF**直接取2.5%和97.5%分位点，作为正确分布已知的预测区间负对照。45个来源的对照覆盖率均≥0.95，仍因离散性可能保守。

### 固定反例 A：同均值、同方差，却出现明显覆盖不足

`n=8, p=1/2, ZIB` 的不活跃混合概率 `1/8`：

* 真实 `E[Y]=4`，`Var(Y)=4`，故离散度 `D=1` **严格等于 Poisson(4)**。
* 真实 `P(Y=0)=103763/823543≈12.599585%`，Poisson(4) 仅约1.8316%。
* Poisson(4) 名义95%区间为 `[1,8]`，按其自身概率计算覆盖率约96.0321%。
* 真实分布下覆盖率 `719780/823543≈87.400415%`，因为真实计数只有0至8，整个偏差恰好来自被排除的0次事件。
* 对照真来源95%区间 `[0,7]`，其真实覆盖率约99.0053%。

即使均值与方差同时准确，单看泊松离散度也无法识别这一零质量与区间覆盖失败。

### 固定反例 B：最严重的过度离散情景

`n=12,p=1/2,ZIB_1_4` 时，`mu=6,Var=14,D=7/3`：泊松名义区间 `[2,11]` 的理论覆盖率约96.2557%，真实覆盖率仅 `131830/177147≈74.418421%`；同源真分布区间 `[0,11]` 覆盖率约99.4219%。相比之下，同 `n=12,p=1/2` 的独立二项来源，在 `[2,11]` 下真实覆盖率 `2041/2048≈99.6582%`。

以上是**已知真实均值**的分布失配边界。真实估计时还有参数误差、时间相关性、分布迁移、事件定义及观测误差，不能直接把上表百分比外推为现实业务数据的风险。
