## Actual schema and access checks
The public data/README codebook defines paper, study, subject, problem, trial, choice, outcome/feedback, decision, response_time, stage, and other metadata. Subject identifiers are described as unique within the source study, so any future cross-study identifier must be composite (paper, study, subject), with problem and trial preserving time order. Repeated decision time unit is a trial within a problem; it is not a dyadic game round unless original study establishes this. No independent session/pair keys have been validated.

Metadata table lists AK2011_1 with 44 participants and 100 trials, KCG2016_1 with 199 participants and 120 trials, and BE1998_1 with 42 participants and 500 trials. These are metadata only. Public contents listing of data/AK2011 and data/KCG2016 showed processing-code R files and README files, with no raw or processed CSV in those directories at this revision. AK2011 README explicitly says no raw data for studies 3 and 4. KCG2016 README flags a separate mismatch: study 2 raw data had 206 participants while the paper reported 207. This is an author-curator note; it has not been independently resolved or reproduced.

No raw or processed human participant records were fetched, parsed, or republished. The public GitHub metadata was inspected without registering an account or using paid access. Access status: BLOCKED pending unambiguous author release/permission, independently usable raw records, and per-study license confirmation. The 100/120/500-trial metadata alone does not establish 100-round dyadic prisoner-dilemma identity, partner history, or independent experiment replication for R073.
