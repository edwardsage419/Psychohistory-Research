# R081: 原作者64真人网络缺测敏感性、机器人实体语义及处理分配审计

日期：2026-10-17。前一阶段 [R080](../R080/README.md) 已有界完成64原作者SHA256核验网络的真人合作率及网络拓扑描述。R081在已知R080真实结果之后，独立先提交[冻结方法协议](../../protocols/R081_AUTHOR_64_NETWORK_ASSIGNMENT_BOT_ENTITY_AND_MISSINGNESS_BOUNDS_FREEZE_2026-10-17.md)（commit `ff1ed84cd99d26c88d0b94c8f86bc2a5173645e3`），明确研究性质为回顾性真人 E2 敏感性分析。

## 已明确的证据边界

* 原作者论文 [Shirado & Christakis (2020), iScience](https://pmc.ncbi.nlm.nih.gov/articles/PMC7452167/) 主文称第一实验56组、第二实验8组，第二实验为**一个逻辑bot具有5条边**；此前R080原始来源的 `single_mgmt_bot` 处理，每网络有**5个 `is_bot=true` 记录节点**。人机记录节点与实验机器人干预实体应分开看，不能以5个节点推出5个独立逻辑bot。该映射尚待底层引擎/原作者编码说明确认。
* 论文描述的随机初始网络和逐轮随机提出重连对象，并不单独证明 **原作者处理分组随机分配**；第二实验采用已根据第一实验结果挑选的混合策略，且跨实验阶段，因此不能把第二实验与第一实验对照直接当作新的已识别因果对比。
* R080记录每64网络各16真人30轮共30720个理论行动槽，其中27656条真人C/D已观测，有3064条没有可观测行动。主结果是 **观测行动上的合作率**。R081将另行计算若为3064个缺失槽补入任意二元答案时，假设所有真人都潜在可以表态的合作变化**精确上下界**。任何界限都不是对缺失原因的诊断或真实合作率的点估计。
