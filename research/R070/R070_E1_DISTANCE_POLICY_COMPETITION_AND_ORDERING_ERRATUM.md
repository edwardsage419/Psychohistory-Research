# R070：15,120 条穷举轨迹证明空间可达性、目标位置选择与代理执行次序相互独立

日期：2026-10-16。**研究等级 E1 数学/计算机制证据，不是 E2 真人迁居或政策因果效果。** 本报告同时更正此前 R070“停滞”解释中容易被误解的地方；旧的原始数值、旧的 Git 提交及 GitHub Actions 记录保持不变。

## 1. 先验规则、数学全集与原始作者区分

本研究在计算前冻结[四政策竞争协议](../../protocols/R070_E1_MOVEMENT_DISTANCE_COMPETITOR_2026-10-16.md)，Git commit `957579cf8cc5d6774e38625f956d84a5079b25c3`。3×3 有 9 个位置，恰有抽象 A/B 各两个代理和 5 个空位；无重复的完整初态 **756**。阈值 `0, 0.25, 0.5, 0.75, 1` 五组；比较四个规则，因此严格 **756×5×4=15,120** 条独立确定性轨迹，每条最多 40 步。跨政策只改变**迁入空位的选择与可达性**，不改变计算满意度的 Moore 八邻域、行优先挑选当前第一个不满意代理、必须搬入满意位置、代理守恒或结束状态。

| 政策 | 合法空间 | 目标的选择 |
|---|---|---|
| `GLOBAL_ROW_MAJOR` | 任意曼哈顿距离 | 按行优先的第一个满意空位，严格对应以前 R070 的原始代码 |
| `RADIUS_1` | 曼哈顿距离 ≤1 | 可达范围内按行优先 |
| `RADIUS_2` | 曼哈顿距离 ≤2 | 可达范围内按行优先 |
| `NEAREST_SATISFICING` | 任意距离 | 优先曼哈顿距离最短，同距离按行优先 |

**关键区别：** 最近满意空位不是硬距离禁令；如果只有远处空位可满意，仍然允许前往。新程序在**每一个**初始配置/阈值上与[原 R070 模型](r070_schelling_spatial_migration.py)基线的全轨迹逐次比较，保持 100% 完全相同。

研究参考 [Gambetta, Mauro & Pappalardo (2023)](https://doi.org/10.1038/s41598-023-38519-6)，他们研究距离和空间位置吸引力制约，但他们实际实现的是随机重力/移动概率与不同规模；**本研究是独立定义的确定性步长对照，不是原论文模拟结果重现**。

## 3. 关键机制审计：先被处理者不动，不代表所有人都无路可走

之前的 `STALLED_NO_SATISFYING_VACANCY` 语义实际是：

> **当前被行优先选中的第一个不满意代理，找不到可以满足本人阈值的目标位置，因此当前程序终止。**

它**并不表示**“没有任何其他不满意代理能搬迁”，更不等价于纳什均衡、空间满意均衡或住房供给的真实不可行性。本轮对停滞时刻另外检查**其余不满意者**是否至少一人存在合法迁居目的地，得到：

| tau | 原 `GLOBAL_ROW_MAJOR` 总停滞初态 | 其中仍有其他不满意代理可搬迁 |
|---|---:|---:|
| 0.25 | 0 | 0 |
| 0.5 | **114** | **114** |
| 0.75 | **546** | **428** |
| 1.0 | **546** | **428** |

因此此前关于“阈值 0.5 有 114 个初态不满意而停滞”的**数值仍正确**，但若据此推断“114 个配置都不存在任何可行迁居”，该推断**错误**。须保留这项正式解释更正。tau=0.75 时，546 个停滞中 428 个至少一名其他代理仍有合法移动，另外 118 个在本次诊断时并未发现任何其他代理有合法移动；**这 118 只是该结束局面下的当前可行性，不代表若改变此前活动顺序也必定无法收敛**。

第一个按字典序可重放的反例：tau=0.5，初态：

```text
1 1 2
2 0 0
0 0 0
```

行优先的第一位不满意代理无满意目标，程序 **0 步停滞**；但存在其他不满意代理有合法空位。此例已加入观察后不可回退测试。

## 4. 不仅有限距离导致停滞，选择更近目的地还可能救出停滞

硬距离的对照：tau=0.5 时无限制基线 **642** 个全员满意，`RADIUS_1` 只有 **294** 个；在 **348** 个原本可以完全满意的同一初态上，1 格距离限制使程序停滞。tau=0.25 时甚至由 756 降到 496（新增 260 个停滞）。

更意外的是，同样可以到达所有空位时，仅将“全局行优先第一个可行空位”改为“距离最短的可行空位”：

- tau=0.5：基线 **642** 个全员满意，`NEAREST_SATISFICING` 达到 **646**，**4 个**基线停滞的初态改为最终全员满意，且未出现基线已满意而新法停滞的情况；
- 原始 tau=0.5 反例初态：

```text
1 0 0
2 0 0
0 1 2
```

基线先迁 1 次后停滞；最近可满意目的地策略迁移 **3 次**达到全员满意。

这不是“最近邻总是优于其他规则”的普遍定理。尤其 `RADIUS_2` 在 tau=0.5 时虽有 **4 个**原基线停滞初态获救，同时还有 **118 个**原来全员满意的初态因限制而停滞，净结果 528 全员满意。**同一政策可能在某些配置救出原来失败者，又使其它配置失败，不能仅据总体计数断言个体水平的单调性。**

## 5. 宏观联系指标并非政策福利比较

本报告仅用占用的四方向相邻格子的 `异类型连接数量/全部占用连接数量` 度量宏观空间接触；若分母为0，不将它伪设为0。在 tau=0.25 下，和全局基线终局可比较的布局中，`RADIUS_1` 有 **212** 个布局异类型相邻比例**更高**，16 个布局更低；`NEAREST_SATISFICING` 的对应高/低计数是 **104/22**。更高的接触比例**不是**自动等于更好的人类公平、社会福利或制度效果，真实经济/供给与身份约束均未输入。

上述强实验结论的精确对象仅是**一个指定异步规则、固定个人初态和阈值下的空间算法**。时间和行为真实性、外部可迁居集合及人类动机均未测试。
