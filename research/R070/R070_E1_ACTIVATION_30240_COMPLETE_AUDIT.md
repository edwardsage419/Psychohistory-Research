# R070：先选可迁居者如何改变群体格局——30,240 条穷举实测与旧停滞语义闭合

日期：2026-10-16。**证据等级 E1（纯抽象确定性代理数学/代码验证）**，不等于现实居民偏好、社会歧视或历史住房政策的因果证据。研究已按协议事先登记，完成 23 项测试与全部 30,240 条轨迹，并核验 GitHub Actions success。

## 1. 研究原因与唯一变化的微观条件

在此前 [15,120 个空间移动距离竞争实验](R070_E1_DISTANCE_POLICY_COMPETITION_AND_ORDERING_ERRATUM.md)中，发现固定程序一旦“最先行优先的不满意者”不能找到满意位置就立即停机，**可能仍有其他不满意代理可以移动**。此前 tau=0.5 的 114 个不限距离“停滞”，事实上全部属于这种激活顺序造成的停机。这不足以证明“系统没有任何可行的移动方案”，故另立新 [冻结实验协议](../../protocols/R070_E1_FEASIBLE_ACTOR_ACTIVATION_2026-10-16.md)，Git commit `fa9d786416e225c97eba4fac31525266321681e1`。

依然固定同一 3×3 棋盘、两类代理各两名、5 空格，共有 **756** 个无重复初态，5 个阈值 `{0, .25, .5, .75, 1}`，4 种迁移目的地政策 `GLOBAL_ROW_MAJOR`（任意距离按行优先）、`RADIUS_1`、`RADIUS_2`、`NEAREST_SATISFICING`（无限距离但先选最近满意目的地）。本轮唯一增加另一种**激活规则**：

- 旧 `FIRST_UNHAPPY`：只尝试行优先第一名不满意者，若搬不了立即停滞；
- 新 `FIRST_FEASIBLE_UNHAPPY`：按原行优先顺序，跳过不能搬去满意空位的不满意者，找到第一名可以搬的人再执行**原来同一目的地排序规则**；全体不满意者都没有可行目的地才标 `STALLED_ALL_UNHAPPY_IMMOBILE`。

两种均不随机、不得换房或去孤立的无邻居空位以造出虚假满意感，必须在搬迁后满意、完全保持 2 A / 2 B / 5 空位；每条最多 40 步，总数 **756×5×4×2=30,240**。原模型实现 `r070_distance_competitors.py` Git blob `e44101fa9bf638eadebe13aec1930d72a524af8c` 保持不改。

## 3. 主要穷举结果

各个阈值/位置政策均跑 756 个初态，下表数据是**最终达到全体代理满意的初态数**（`旧→新`），不是样本问卷满意比例。

| 阈值 | 任意距离行优先 | 距离 ≤1 | 距离 ≤2 | 最近满意空位 |
|---|---:|---:|---:|---:|
| 0 | 756 → 756 | 756 → 756 | 756 → 756 | 756 → 756 |
| 0.25 | 756 → 756 | **496 → 600** | 720 → 720 | 756 → 756 |
| 0.5 | **642 → 756** | **294 → 362** | **528 → 666** | **646 → 756** |
| 0.75 | **210 → 570** | **90 → 186** | **170 → 442** | **210 → 570** |
| 1 | **210 → 570** | **90 → 186** | **170 → 442** | **210 → 570** |

**最显著：** 不限距离、`tau=.5` 时旧模型 114 个停滞全部被新激活规则救出，**756/756** 达到全员满意；`tau=.75` 时旧 210/756 增至 570/756、仍有 **186/756** 全体不满意者无可满意目标。半径1、`tau=.5` 时虽有 **68** 个旧停滞被救出，新模型仍有 394 个真正“全体不可迁居”停滞；物理距离约束并没有随着跳过第一个代理而消失。

**旧停滞被救出的逐一配对计数**：`tau=.25` 半径1为 104 例；`tau=.5` 任意/半径1/半径2/最近优先依次为 **114/68/138/110** 例；`tau=.75` 则为 **360/96/272/360** 例（`tau=1` 结果相同）。所有 20 个政策×阈值组中，**没有“旧全员满意、新规则反而因所有人不能搬而停滞”或新增 40 步预算耗尽的案例**；但此结果仅限指定 3×3 规则，不可写作任何总体算法/现实社会普遍定理。

## 4. 真实的规则层反例与两种停滞的分界

tau=0.5、基线政策 `GLOBAL_ROW_MAJOR` 的字典序最先反例：

```text
1 1 2
2 0 0
0 0 0
```

旧规则在**0 次**迁移后停滞（第一名不满意者无合法目的地）；新规则跳过首位堵塞者，经过 **2 次**合法迁移达到全员满意，终局：

```text
1 1 0
0 0 0
2 2 0
```

此反例明确说明旧的 `STALLED_NO_SATISFYING_VACANCY` 并不是每个人都无处可去。新 `STALLED_ALL_UNHAPPY_IMMOBILE` 必须在代码中逐一检查**全部当前不满意者**的合法空位集合均为空；但即便如此，也只证明在**当前局面/当前规则**暂时无一步满意搬迁，不是证明所有可能历史路径均无满意终局、或者稳态意义上的真实纳什均衡。

**宏观结果也不能直接写成“每次移动改善群体福利”。** 对阈值 .75 的不限距离模型，新规则比旧模型具有更高的终局异类型四邻接接触比例的初态有 **24** 个、更低的有 **308** 个；即使“最终不满意者人数”没有比旧模型更多的案例，另一个宏观接触指标也未必朝同方向改变。在半径1、`tau=.5` 时，新规则的异类型接触比例比旧政策更高的初态有 **40** 个、更低的 **56** 个。不能将宏观接触数高低单方面等同人类福利/隔离正义。

## 5. 前次解释修订与范围承诺

这一轮与上轮对第一名不满意者锁定的发现，完整地关闭了一个**模型解释问题**：

- 前期 [R070 3,780 全状态总结](R070_E1_3780_CASES_ROBUSTNESS_AND_MODEL_SCOPE_REPORT.md)中曾容易产生“没有任何满意空位，因此全局不可迁居”的过强解释；此前已补正式勘误。新结果显示 tau=.5 的 114 个旧“停滞”都是**因代理激活次序造成**，若允许选择下一名可搬者便全部可以在规则内迁移到全员满意。
- 在 tau=.75 和 tau=1 的旧 546 个停滞中，原来有 428 个存在至少另一名可动代理；本轮的不同路径结果是 **360 个**最终被救出、186 个终局仍不能搬迁。原因包括迁移顺序造成后续局面的差异，不能将 428 直接改写成可救出人数。
- 同一个极小人口下 tau=.75 与 1 在所有完整枚举中轨迹相同，是离散同类邻居比率的结果；不是关于现实集体偏好的发现。

以上只是数学机制与可复现程序的内部有效性。作为可验证的 E2 人类空间迁居机制，当前仍缺少真正逐动作数据、时点上可见空房/迁入的候选集合以及与既有 [Tsvetkova et al. (2016) 真人实验](R070_E2_HUMAN_GAME_SOURCE_ELIGIBILITY_AUDIT.md)完全匹配的即时决定规则；作者的开放论文结果不能变成本研究的真人独立验证。真实住房价格、信贷、迁居成本、歧视政策等制度驱动力均未引入。
