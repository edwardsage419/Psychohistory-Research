## 1. 研究动机与证据协议

R070 前一项基线使用 4×4 抽象版图，两类型各 2 名、12 个空格，固定满意度阈值 0.5，确定性迁移 3 次后全员满意且四方向占用格的异类型连接比例从 0.5 降到 0。但这只是**一个初始配置**，既不能推断其它初态也会收敛，更不能断言局部满意搬迁总是增加群体间空间隔离。

因此**在首次执行批量计算之前**先提交[全状态穷举协议](../../protocols/R070_E1_EXHAUSTIVE_SMALL_BOARD_ROBUSTNESS_2026-10-16.md)，commit `1f01324c45cdda37cd0c6f0adf763550f4db9fc1`；严格重用现有 [R070 有确定性规则的原始代理实现](r070_schelling_spatial_migration.py)，不替换选择顺序或阈值公式。

3×3 有九个位置，恰有 A 类型 2 个、B 类型 2 个、空位 5 个。完整宇宙 C(9,2)×C(7,2)=**756** 个无重复板面。阈值 `0,0.25,0.5,0.75,1` 五种，合计 **3,780 个固定实验**，每个最多 40 次异步迁移。无可行满意空位的结束状态必须标 `STALLED_NO_SATISFYING_VACANCY`，且**绝不能**偷换为全员满意；没有任何配置达到 40 次上限。结果完全是 **微观迁移规则的条件性数学性质**，不存在真实人类受试者或置信区间。

## 3. 两个真正得到的可反驳反例

**反例 A：局部选择无可行搬迁，因此不能全部收敛。**

阈值 tau=0.5，3×3 初态（1=A、2=B、0=空）：

```text
1 1 2
2 0 0
0 0 0
```

运行状态 `STALLED_NO_SATISFYING_VACANCY`，搬迁 0 次，仍有 **3 个不满意代理**。在该 tau 的 756 种布局中共有 114 种出现此类停滞；阈值达到 0.75 后增加到 546 种。若把“模型停止”直接称作“稳定、全体满意、群体达到均衡”，会系统性混淆真正已满足与缺失可行选择。

**反例 B：个人向满意空位迁居可能使宏观异类型邻接比例反而上升。**

阈值 tau=0.25，3×3 初态：

```text
1 1 0
0 0 2
2 0 0
```

仅 1 次确定性迁移，初始四邻接异类型占比 **0**，终点 **1/3**。在 tau=.25 的完整集合中，**24 个布局**最终该宏观比例高于初始值；在全轨迹中有 **30 次有可比较分母的单步移动**提高了这一比例。即便整个宏观均值平均有所下降，任何“每一局/每一步必减少异类型接触”的绝对命题仍已被反例推翻。

## 4. 不同阈值表现相同的严格解释

在这个 3×3 极小场景中，**每一类型仅有两名代理**，所以每位代理最多只有 **一位同类邻居**。对有至少一名邻居的代理，其可取的同类比例仅为 `0,1/3,1/2,1`；完全无邻居则视为满意。因此阈值 .75 与 1.0 对所有位置的满意与否条件**完全一致**，迁移规则及确定性行优先扫描自然产生完全相同的 756 条轨迹。17 项新测试确实在全 756 配置上逐轨迹检验此不变量。

这种阈值“等价”源于固定人口规模和离散局部比率的数学格点，**不是人群在 75% 和 100% 同类偏好下都会产生同样行为**。

## 5. 现实对照与不能跨过的实证关口

[Tsvetkova et al. (2016)](https://doi.org/10.1140/epjds/s13688-016-0065-5) 公开研究中有 399 名 16–19 岁高中生、20 个班级、6×6 四类实时空间游戏，真实参与者按局部可达空位移动并可交流。论文主要结果被公开，可作为**真正人类行为对照候选**；但本项目尚未取得任何逐动作数据的不可变哈希/可再用许可，也尚未复现这 399 名真实被试的机制选择、移动或班级留出预测。不能将他们的论文报告和我们的小板面 E1 合并成 E2 成功。

[Gambetta et al. (2023)](https://doi.org/10.1038/s41598-023-38519-6) 关于移动成本/距离限制的原作者 [公开模型](https://github.com/dgambit/mobility_schelling) 已核验 Git commit `08e51e8592db813b05e93d9a98f43dd5e62d9572` 和代码 blob `2ab1dc0e75c4f7d1ea9b66d7f37c4a355457998f`；作者 README 明确说仓库数据**由模拟生成且没有真人参与**，所以该来源可用于设计下一种竞争移动机制，不可冒充真人实证。
