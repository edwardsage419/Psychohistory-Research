# 单次追加观测的离散行动门槛：合成方法卡（2026-11-22）

## 适用问题与去重
服务个人决策系统“已有调查结果，是否值得再取一个样本”的局部决策能力。前置研究 `VOI_POSTERIOR_CONDITIONAL_EVPI_AFTER_OBSERVATION_2026-11-22.md` 给出完全信息价值上界；本卡计算**一次真实可执行的追加伯努利观测**的条件 EVSI，避免把 EVPI 上界误当作具体调查收益。未修改前置研究和冻结记录。

## 输入、假设、步骤
仅适用于合成例：最初 Beta(1,1)，已有 n=15000 个独立、同分布、无测量误差的伯努利样本，其中 k 个事件。行动为执行调查（相对基线效用 g(p)=1.5−6p）或不执行（效用 0）。追加一次独立同分布观测，成本 C 与效用单位相同，且观测不会改变真实 p、行动集合和效用。

令 a=k+1，b=15001−k，N=a+b=15002。当前最优后验期望效用
`U0=max(0,1.5−6a/N)`。
追加样本 Y 的预测概率 `Pr(Y=1)=a/N`，后验为 Y=1 时 Beta(a+1,b)，Y=0 时 Beta(a,b+1)。
`U1=(a/N) max(0,1.5−6(a+1)/(N+1))+(b/N) max(0,1.5−6a/(N+1))`。
`EVSI_1=U1−U0`；净收益 `EVSI_1−C`。严格大于零才建议取样；等于零为平局。此为预期收益规则，未赋予频率置信覆盖保证。

## 最小可复算算例（本轮本地 SciPy/Python 数值点检）
| k | U0 | EVSI_1（一次追加样本） | 前置条件 EVPI 约值 |
| ---: | ---: | ---: | ---: |
| 3600 | 0.059792027729636 | 0（浮点残差约 1.1e−16） | 0.00001445 |
| 3749 | 0.000199973336888 | 0.000024991668777 | 0.00836234 |
| 3750 | 0 | 0 | 0.00836259 |
| 3900 | 0 | 0 | 0.00001489 |

关键离散反例：k=3750 时，虽然完全信息价值约 0.00836259，一次追加观测无论结果如何都不会使后验最优行动从“不执行”改变，因此单次 EVSI 精确为零。k=3749 时一次观测可能改变行动，EVSI 为正。对于 k=3749，成本 C=0.00003 时净收益为负；C=0.00002 时为正。追加多次样本的联合价值可能为正，不能由一次样本 EVSI 为零推断任何规模的调查均无价值。

## 简单基线、失效与接入建议
基线：无需追加观测，直接按当前后验期望收益选行动，价值 U0。工程候选应同时显示当前最优行动、一次追加样本 EVSI、完全信息上界、成本和先验来源。禁止仅凭 EVPI > C 宣称某次具体调查值得做；无可信先验、成本、样本独立性或效用量纲时展示 UNKNOWN 与情景条件。实际用户仍决定效用权重及最终行动。

## 验收与证据等级
独立验收轨：用有理数或高精度十进制独立复算 k=3749/3750，验证 EVSI>=0、EVSI<=条件 EVPI、成本平局及追加一次观测无法改变行动时 EVSI=0；对非独立样本、未知先验与可变行动集合进行拒绝或降级测试。数据轨负责真实抽样机制、成本与先验依据。当前仅完成本地合成算例点检和公式整理，未完成外部独立验收、现实效果验证或工程接入。公式属于 Beta 共轭更新和期望效用直接推导；本轮未逐式核对原始学术文献，不宣称文献级科学验收。零新增费用，无私人数据、CI 或计费 API。
