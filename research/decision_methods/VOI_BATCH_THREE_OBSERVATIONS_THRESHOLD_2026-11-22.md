# 三次追加观测与单次零价值反例：合成方法卡（2026-11-22）

## 决策缺口与适用范围
接续 `VOI_SINGLE_ADDITIONAL_OBSERVATION_DISCRETE_GATE_2026-11-22.md`。该卡明确一次追加观测 EVSI 为零时，多次联合采样仍可能有价值。本卡给出最小的具体反例，供个人决策系统避免错误地停止全部信息收集。仅限合成 Beta 伯努利模型，不代表现实个人调查的收益。

## 输入、假设、计算
原先验 Beta(1,1)，已观测 n=15000 次独立同分布伯努利试验，事件 k=3750 次。当前后验 a=3751、b=11251、N=15002。执行行动的期望效用为 `1.5-6p`，不执行为零。后续固定追加 m 次独立同分布观测，新增总成本 C，结果观测后才选行动；不允许中途停止，效用与概率不因观测改变。

基线 `U0=max(0,1.5-6a/N)=0`。
令 J 为 m 次新增事件数，预测分布为 Beta 二项：
`P(J=j)=binom(m,j) (a)_j (b)_(m-j)/(N)_m`，其中 (x)_r 为上升阶乘。
`Um=sum_{j=0}^m P(J=j) max(0,1.5-6(a+j)/(N+m))`。
`EVSI_m=Um-U0`，净价值为 `EVSI_m-C`。

## 最小算例和离散反例
以 Python 标准库 fractions.Fraction 及整数乘积进行精确有理数求和，最后才转换为十进制：
| 追加观测 m | 条件 EVSI_m（效用单位） | 解释 |
| ---: | ---: | --- |
| 0 | 0 | 当前最优行动不执行 |
| 1 | 0 | 两种后验结果均不执行 |
| 2 | 0 | 所有结果仍不执行 |
| 3 | 0.0000421706311020 | 三次全为非事件时，执行的后验收益转正 |
| 4 | 0.0000632531364018 | 批量信息价值继续增加 |

对于 m=3，只有 J=0 时执行的后验期望效用严格为正。其值为 `1.5-6*3751/15005=0.0000999666777741`；其余结果不执行。成本 C=0.00003 时，三次固定追加观测净价值约为 +0.00001217063，而一次与两次采样净价值均为负（只要各自成本为正）。若三次总成本 C=0.00005，三次净价值为负。成本比较必须使用各方案对应的总成本，不可将单次成本误作批次总成本。

## 简单基线、限制和失效条件
基线是不追加样本，维持当前行动；另一基线是逐次贪心，仅在下一次 EVSI 严格大于成本时采样。此例中逐次贪心可能停在零价值处，错失预先承诺的三次采样收益。批次策略需要事前支付或承诺相应成本；允许中途停止时须另建序贯动态规划模型，不能直接套用固定批次结果。

所有数字依赖特定先验、样本独立同分布、完全可观测、固定效用及两行动。现实问题缺少可信先验、有效采样机制或成本时，结论标记 UNKNOWN；不应向用户承诺采样有效。
