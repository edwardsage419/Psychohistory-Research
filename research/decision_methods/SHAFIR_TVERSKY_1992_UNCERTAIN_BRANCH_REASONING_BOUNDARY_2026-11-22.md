# Shafir 与 Tversky（1992）：未知状态下的分支推理与决策延迟
实际研究日期：2026-11-22。研究轨：个人决策理论。候选研究，未获科学验收。

## 决策缺口
用户可能在每一种已知情景下都倾向采取同一行动，却因为当前尚不知道情景结果而推迟行动。系统需核查是否遗漏了状态分支、是否确实存在等待信息的价值，以及等待是否改变实际可行性。

## 文献事实与解释边界
作者讨论：在已知事件发生和已知事件不发生时均倾向选择 X 的参与者，在事件结果未知时仍可能不选择 X。作者将部分现象解释为未充分逐一考虑不确定状态的后果；当参与者意识到各状态下的选择时，原始摘要报告一致性改善。这是实验和解释框架，无法据此断定任何具体用户存在认知偏差。实际状态可能影响行动成本、期限、未来信息、心理负担和选项集合，需分别核查。

## 候选提问及解释规则
默认先给初步条件分析。仅当未知状态会影响推荐或等待成本时，询问：“假如结果是 A，你会怎么选？假如结果是 B，你又会怎么选？等待知道结果会改变什么？”
记录每一状态下的可行方案、硬约束、用户确认偏好、等待成本和期限。若用户在全部已覆盖的互斥且穷尽状态中均确认同一方案，且行动后果、可行性与信息条件符合比较前提，提示该方案在已列状态中稳定。仍需检查遗漏状态及未知条件。不得推断未知状态概率，不得强制用户立刻行动，不得把选择稳定等同于个人最佳决策。
与 Ellsberg (1961) 的未知概率来源区分：本项关注未知结果下是否逐一审视行动分支；与 Tversky Kahneman (1981) 的等价语言框架区分：本项关注状态条件化选择。

## 六项合成失效反例，均未执行
1. A、B 两状态都选 X，但系统自动捏造各为 50% 的概率，应失败。
2. A、B 都选 X，实际上还存在未列出的 C 状态且 X 违反硬约束；声称无条件稳定，应失败。
3. A、B 都选 X，但等待可以免费取得具有行动价值的新证据；强制立刻执行，应失败。
4. A、B 都选 X，但 A 状态的 X 已过截止时间；忽略可行性，应失败。
5. 两状态下用户选择不同方案，系统把未知结果误当成已观察状态并直接确定行动，应失败。
6. 用户表示无论哪种结果都选 X，但 X 在其中一个状态造成不可承受损失；系统未询问硬约束即推荐，应失败。

## 竞争解释与局限
推迟选择可能来自真实信息价值、风险规避、行动成本、选项可逆性、社会规范、焦虑或决策疲劳。实验样本、具体任务及原始统计尚未完整审查；没有估计个体效应或推广系数。未执行代码、复算、独立验证、真实用户效果验收。
