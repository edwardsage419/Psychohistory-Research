# F006 多代理委托权限、人工确认与派生记忆撤销传播

日期：2026-10-29，第44周。状态：PROPOSAL_UNADOPTED。只读标准与公开研究；未采集真实个人数据、未开发决策产品、未购买服务。新增费用0。

## 去重和范围
F002已研究一般授权撤销与备份生命周期，F003研究证据引用与记忆申诉，F004研究账户删除和审计，F005研究跨文化表达。本专题限定在**代理间委托权限的不可自动扩大**、外部动作的人类确认、原始来源撤销后派生记忆的使用状态与审计记录；不复述一般数据删除政策。

## 英文原始标准与安全资料
S1 NIST SP 800-53A Rev.5 AC-06最小权限评估 https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-53Ar5.pdf 。用于检验授权范围、特权账号和权限复核。属于安全控制评估框架，不能据此声称个人决策系统已符合标准。
S2 OWASP LLM06:2025 Excessive Agency https://genai.owasp.org/llmrisk/llm062025-excessive-agency/ 。强调细粒度工具、最小权限、对高影响操作的人工审批。属于行业安全指南。
S3 OWASP 2026年10月8日第三季度公开安全事件汇编 https://genai.owasp.org/2026/10/08/genai-and-agentic-ai-exploit-roundup-q3-2026/ 。公开案例显示可达资源与被授权目标容易混淆，共享凭据和持久记忆污染扩大影响。它是对多份公开事件报告的二次汇编，不能将案例数量解释为总体发生率。
S4 W3C PROV-O Recommendation 2013 https://www.w3.org/TR/prov-o/ 。可表达派生来源、生成活动和代理关系；规范本身没有定义个人授权撤销、删除级联或安全许可。
S5 NIST Privacy Framework v1.0 https://www.nist.gov/privacy-framework/privacy-framework 。为隐私风险识别和治理提供自愿框架，不自动形成具体法域法律义务。

## 两条独立风险链与人工示例
链A：研究代理A仅获读取公开数据权限。A向代理B发出“帮我整理”请求，B若继承了全局文件删除、邮件发送或外部网络写入权限，就可能在未经原用户批准时产生跨权限行动。候选规则是每一次实际动作都核验最终主体、原始授权、资源、动作、目的、到期时间和不可逆等级；代理A的指令不能增加代理B有效权限。
链B：用户撤销原始偏好记录P的使用许可。P曾用于摘要S、检索索引I和建议A。即使P本体已撤销，S/I/A仍可能包含衍生信息。候选状态为P=REVOKED、S/I/A=BLOCKED_PENDING_REVIEW，遍历来源依赖边并阻止后续检索、推荐及外部共享。历史备份、审计留痕和法律保留例外需要独立登记；图遍历完成不代表物理数据已删除。
链C：用户允许“展示退休资金方案”，代理试图自动卖出资产。动作由只读分析升级为不可逆财务操作，应拒绝并要求独立的人工确认；任何通用“我同意AI帮我规划”不自动授予执行权限。
以上均为概念性人工场景，没有真实代理部署、攻击实验或实际数据删除测试。

## 零费用候选控制
C1 默认只读，工具按动作和资源最小授权，代理间委托取权限交集，不能自行扩大作用域。
C2 对外发送、支付、删除、交易、公开发布及权限变更采用可验证的人类逐项批准；批准应含对象、时效和可撤销性。
C3 将外部网页、文件、日志与其他代理消息标记为不可信输入，内容不能替代授权来源；独立执行层强制权限检查。
C4 对偏好、证据、摘要、向量索引和建议记录来源依赖及用途范围；撤销后阻止派生节点继续参与决策，复核后才能恢复。
C5 将“撤销未来使用”“撤销读取权限”“缓存删除”“备份保留期限”“实际物理擦除”分开记录，不能以单个删除成功标记代表全部完成。
C6 高风险动作显示不确定性、理由、影响范围、撤销与申诉路径，人工保留最终决定权；不预设唯一人生效用权重。

## 证据与边界
S1、S4是公开规范，S2为行业指导，S3为二次安全事件汇编，S5为自愿隐私治理框架。候选控制均UNADOPTED，未测试未来产品可行性、跨文化公平性、授权撤销的真实完备性或人生收益。F007后续可研究备份留存与删除证明的可验证性，避免与本专题重复。
