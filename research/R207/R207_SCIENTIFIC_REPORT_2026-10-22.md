## 真实数学来源与方法边界

Candès and Recht (2009), [Exact Matrix Completion via Convex Optimization](https://doi.org/10.1007/s10208-009-9045-5)（*Foundations of Computational Mathematics* 9:717–772），研究低秩矩阵随机元素抽样和核范数优化恢复的条件。另见正非零rank1矩阵的二部观察图连通性讨论 [Matrix Completion with rank-one graph condition](https://math.mit.edu/sites/icg-old/papers/matrix-completion-sdp.pdf)。本R207是另一项**有界小规模机制审计**：固定3×3正rank1源，穷举所有5个观察位置及所有原因子，研究观察图结构导致的有限补全可辨识性和已知有限生成先验下的Bayes条件均值误差。本研究**没有**执行核范数最小化、Candès–Recht原优化算法、一般rank-r恢复或真实矩阵基准的原论文复现。

真正源生成由六个独立均匀潜在行/列因子u0,u1,u2,v0,v1,v2∈{1,2}给出，Mij=ui vj，正无噪声矩阵取值∈{1,2,4}。因子来源64条，按原因子历史等概率1/64，其中不同因子路径可能产生相同全矩阵；因此贝叶斯后验必须按**64原因子路径频率**加权，不得先按不同矩阵去重再赋予均匀先验。

原9矩阵元素中对每一种恰5位置观察掩码Ω，共有C(9,5)=126种不重复掩码，**所有126种、没有人工挑选**。每种掩码独立观察5个固定位置，真正剩余4个矩阵元素屏蔽给补全程序。64原潜在路径×126掩码形成**8064条原完整人工评价记录**，每一记录保留64来源之一的6个因子、真9矩阵元素、5个实际可见位置与值、4个留出真值、三个补全算法的4个预测值和各自4个真实平方损失。共32,256条被评价的人工缺失项误差。掩码是事前固定且与真来源独立的观察设计条件，同一矩阵里的缺失4值高度依赖，**不能把32,256个条目说成32,256次现实独立实验或新矩阵前瞻预测**。

## 三种固定补全方法与真正同矩阵留出测试

**有限先验Bayes后验均值oracle**：仅使用mask五个实际观察条目，以及已事前固定的64原因子先验，筛选所有产生完全相同观察值的来源因子路径，对其未观察的各位置取真正等权条件平均。真实隐藏4条从来不输入估计器。该补全器得到的是已知正确离散生成分布时的理论最优条件均方预测，优势来自知道原有限先验；不能将其归功于一个在未知真实数据上已验证的通用补全算法。

**可见条目均值补全基线**：取五个已观察值的平均填入所有四个缺失项，不利用因子模型或隐藏真值。**零补全基线**：全部预测0，也不使用任何未来真值。三者均在相同屏蔽位置报告4条平方损失的均值，再在每掩码64真来源完整概率加权，最后在同一连通组的不同mask均等加权，严格分离信息权限与mask条件。

后验Bayes实际平方误差采用两条真正独立有理数计算：
1. 对每个原真来源，把其4个隐藏真值逐条与依据**可见5个值**算出的后验均值比较，再按mask内64原因子来源概率和4个缺失位置取平均；
2. 对同一mask的64原潜在因子来源独立按5个观察值签名分组，直接由每组未观察条目的真实**条件方差**用方差公式E[X²|obs]−E[X|obs]²求出，按签名来源频率和4个缺失位置取平均。126个mask全部逐Fraction精确相等。每mask还记录固定有限先验支持下的真实矩阵唯一补全概率；必须将此概率与无先验、连续正rank1的图识别条件严格区分。

## 二部观察图连通性完整枚举

3行和3列对应6个顶点Ri、Cj，观察一个位置即在两个顶点之间添加边。五个位置形成**连通六顶点图**时恰为生成树，带标签的K3,3有3^(3−1)×3^(3−1)=**81**个五边生成树；因此另外45个五观察图不连通。程序对全部126图分别以**BFS和Union-Find两个独立路径**验算81/45逐图完全一致。只有此处所有正值且rank1、观察图连通的条件下，沿边比例传播可以无歧义恢复真实全矩阵；本研究的有限先验Bayes在81个连通世界中遂逐来源精确补全所有被隐藏元素。

## 同观察五条、不同完整正rank1矩阵的明确反例

在不连通观察mask Ω=`00|01|10|11|22`，矩阵A的全部9元素均为1，等价真正u=(1,1,1)，v=(1,1,1)；矩阵B由u=(1,1,2)，v=(1,1,1/2)的外积生成：
```
A = [ [1, 1, 1  ], [1, 1, 1  ], [1, 1, 1] ]
B = [ [1, 1, 1/2], [1, 1, 1/2], [2, 2, 1] ]
```
两矩阵全部9元素均正、均严格rank1，在**所有五个实际观察值**上完全一致：四个左上2×2元素是1，右下元素也是1；但四个真正未观察条目值不同。这是关于**无限连续正rank1候选空间**的严格不可辨识数值证明。B的因子v2=1/2超出了本实验已知有限{1,2}先验，正因两种候选空间不同，固定小离散先验可能使部分不连通来源偶然唯一。**7/80的有限唯一概率不可冒充对连续正rank1的结构识别保证**，更不可推断现实的社会联系图与未观察关系能够唯一还原。
