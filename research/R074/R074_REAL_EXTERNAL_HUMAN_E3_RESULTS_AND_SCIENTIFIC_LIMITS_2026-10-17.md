# R074：第二独立真人重复博弈的冻结模型跨实验复验

日期：2026-10-17。性质：**不同原作者、独立实验数据、真实原始配对动作、整场次留出 E3 条件预测结构复验**。R073 原来12场18424次评估的 E2 不变；PESEN v0.1 不升级。

## 1. 有界结论

**R073 的“在本人上轮行动之外加入上轮对手行动可提供额外条件预测信息”在另一份真人实验中再次成立**：M3 − M1 在18场严格等权 Brier 为 **−0.022915328373344184**，**16/18场改善、2/18场恶化**。六个预先分层实验条件中，5种平均改善，1种平均变差（R=32, δ=0.5）；因此不得声称任一制度、任一场次必然收益。

**R073 的“双方前两轮的16态历史优于上一轮4态历史”没有在这个独立实验中复现**：M4 − M3 的18场等权 Brier 为 **+0.003170501040435799**，**5/18场改善、13/18场恶化**。6个条件中仅 R=32, δ=0.75 的平均值微弱改进(−0.00012024)，其余5条件平均变差。这是预冻结模型竞争的真实负结果，禁止后见地修改 alpha/模型后混入原研究结果。

## 2. 真实来源与评分协议时间先后

来源预审 [GitHub Actions run 38988443861](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/38988443861) 在未评分前成功；9项虚构数据测试；原作者真实 **37,042条本人行动、18个独立实验场次、266个场次内参与者身份、18,521个双人配对轮**，6个 `r={32,40,48}` × `delta={0.5,0.75}` 处理，每处理3场。原始不等长 match 中完整 `t>=3` 双方行动历史的测试目标总计 **15,338**。真实评分程序额外强制拒绝 `id` 跨实验日期的数字复用，实际通过；只可说明**公开记录中的数字ID未跨场次复用**，物理受试者从未跨场重返仍缺独立 roster 证明。

在第一次 R074 真人模型评分前，新建 [冻结转移协议](../../protocols/R074_DALBO_AUTHOR_INDEPENDENT_HUMAN_E3_TRANSFER_FREEZE_2026-10-17.md)，独立 Git commit `706d62a0f740262e20fed7bdec5c80cd97c4edd1`。沿用 [R073 原生程序](../R073/r073_human_ipd_memory_loso.py) Git blob `c8a0b47fd27bf05e7be5b87419a0824355fc911a` 的相同七个模型函数及 Brier/log loss，`alpha=20`，M5/M6噪声`0.05`，不动任何模型复杂度。每次完整 `date` 场次留出，只从同处理其他2个完整场次训练，所有模型在**相同本场 t>=3 事件风险集合**上比较，场内平均后 18 场等权；绝不跨 match 串接历史，不把当轮对手行为喂给预测器。每处理分开报告三场等权结果和成败个数，无未经预先注册的小样本显著性测试。

## 6. 能被支持的科学命题与开放问题

跨两个不同团队的真人重复囚徒困境实验，已观察短期的**上轮本人动作与上轮对手行为联合**能够改善下一次个人 C/D 概率预测（整场次留出的宏平均）。但 **two-lag 16态复杂度的泛化收益不稳定**，第二实验还显式呈现反例。分数不能判定人脑采用了哪一种策略、反馈是否有因果作用、公开信誉和制度激励机制是否成立、或者能否预测历史变化。

R073与R074训练的参数分别来自**各自实验内部其它场次**，外部复验的是冻结的特征/模型/评分结构，而**尚未检验将R073拟合好的数值参数零样本迁移**。R074实验超级博弈可随机结束，t>=3只有足够长的配对局出现，因此解释范围条件于局长；不可把此有条件风险集合推广到所有参加者所有局的所有轮。处理间不同收益及延续概率关联不可直接当随机因果因素解释；当前只核验数字ID未跨 session 复用，真实生活中是否重复报名缺独立记录。

建议下一研究段优先完成**第三个独立真人实验**及不同任务形式下的外推，或在一份结果前重新冻结的全新实验上做零样本参数迁移；不得在已经看过 R074 结果的样本上重新选alpha、模型阶数或宣传“找到普遍最优记忆深度”。
