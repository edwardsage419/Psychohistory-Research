# R071：群体规范与制度惩罚研究的开放科学问题

2026-10-16。R071 已完成的范围是**自制五人条件规范/惩罚/监测成本 E1 数学模型和真人原始来源的适用性审计**。以下门并未因 672 合成案例完整执行或 E1 测试通过而解决：

| 问题 | 证据状态 | 继续条件 |
|---|---|---|
| Dryad 2022 随机惩罚真人原始 CSV 实读 | SOURCE_UNRESOLVED | 官方 `noisy-PGG.csv` GitHub Actions HTTPError，原始 SHA/行/列均未取得；应利用合法官方数据 API/明确发布许可，而非假定文件存在即可重算 |
| R047 公共资源提取与 R071 二元贡献对齐 | BLOCKED_MODEL_MISMATCH | 32个四人多级提取组与五人固定策略组不等价，不应任意二值化再称原模型有效 |
| 首轮公开合作规范的真实测量 | OPEN | 需要真实先验期待、是否看到了他人行为、信息可用性；本模型的 initial_norm 是外生控制，不是从被试心理测出 |
| 惩罚角色是否固定及他人预期是否与真实决定对应 | OPEN | 当期惩罚对象、可处罚资格、制裁成本、实际付款、未处罚的风险集、被试制度认知 |
| 反社会惩罚（对高贡献者制裁） | NOT_IMPLEMENTED | R071 只处罚当轮不贡献者，不能解释跨文化反社会惩罚；可对照 Herrmann et al. 数据与新协议 |
| 固定监测成本与处罚效应能否分离 | E1_ONLY | 两者行为规则共享威慑罚额，因此成本只影响付款，现实可能因惩罚者退出/改变角色而改变行动 |
| 条件合作究竟来自社会规范还是收益规则误解 | OPEN_COMPETING_MECHANISM | Burton-Chellew et al. 数据提示理解/混乱等竞争解释，需要独立可识别测试 |
| 策略频率改变、文化传播与群际复制 | NOT_IMPLEMENTED | 当前 C/D/P/N 人数固定8轮，尚无变异、迁移、模仿、制度选择或代际文化变迁 |
| 有害罚款vs转移支付会改变结果 | OPEN | R071 明确将罚款视为纯损耗；政府回收、再分配或返还制度须不同账务模型 |
| 公共物品收益 `b/n` 和动态最优选择 | OPEN | 当前简单自制机械规则，不是针对 Fehr-Gächter 或 Boyd 原模型的参数估计 |
| 真实独立样本/跨制度复现 E3 | OPEN | 本轮只有 E1 数学反例与公开来源元数据，未取得新的真实行为总体 |
| PESEN v0.1 模型参数采纳 | FROZEN | 严禁因 E1 运行成功自动修改主模型 |

**归档：`R071=CLOSED_BOUNDED`，限 E1 自制机制与来源边界；`E2_HUMAN_BEHAVIOR=NOT_ESTABLISHED`，`E3=OPEN`，`PESEN_v0.1=FROZEN`。** 后续新的规范、制度与文化演化研究建议另立 R072（制度信誉/惩罚行为学习/跨群体传播），不要从 R071 研究成功代码推断真实人类规范因果。
