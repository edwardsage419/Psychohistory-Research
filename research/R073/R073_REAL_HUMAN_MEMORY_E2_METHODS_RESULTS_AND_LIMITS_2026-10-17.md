# R073：18424次真人个人下一轮合作选择中，社会反馈和二轮记忆的留场次预测价值

日期：2026-10-17。**科研证据等级：同一作者同一个实验内部的真实真人 E2 条件预测**，不是 E1 合成机制；但**不是因果记忆效应、不是独立E3，也不是现实历史演化预报**。代码没有训练 GPT 基础权重；PESEN v0.1 继续 FROZEN。

## 一、研究来源和为什么跳过 R072 的处理码问题

一手原文 [Montero-Porras et al., Scientific Reports 2022, DOI 10.1038/s41598-022-11654-2](https://doi.org/10.1038/s41598-022-11654-2) 报告布鲁塞尔实验室重复100轮的囚徒困境，固定伙伴FP与每轮打乱伙伴SP两种处理。作者的 original HMM以玩家上一轮自己与对手的四种 `CC/CD/DC/DD` 信息推断策略，本项目**不复算其HMM/聚类**。真实效用 R=3,T=4,S=0,P=1，经典PD自身的单轮最佳反应始终背叛，长期合作涉及历史反馈而不是单轮资源优化。原文 DOI 的终版 Dryad `10.5061/dryad.37pvmcvmk` 曾因网络401/403无法独立固定字节。

R073 **只使用作者已核验的投稿版Git仓库** `eladiomontero/PairwiseStrategies` tag submission commit `4743f74d8a03a031b8f70aff64956f8ad5155182`：
`fix.csv` exact Git blob `3bf78bf85f6642afee18d6f1965dca7272582f40` / 988279 bytes，`rand.csv` blob `f5a86cd033b739da45d3fc7c5019068f612146a2` / 1112614 bytes。每次真实作业在 runner 临时下载后再次通过R067原始安全审计的 exact byte/Git blob/ C/D /处置/轮次唯一性，不把任何原始人类行保存到Git或发布到本仓库。**投稿版与Dryad最终版字节是否相同仍 UNKNOWN**。

R067此前对同一作者数据进行了 **12场次合作比例的一阶预测**；这轮R073问题完全不同：**真正个人层次，在既有历史已观察下预测个人下一轮C/D**。两轮记忆、相同评分人次及隐私统计是全新冻结协议，不能拿两个项目不同损失/预测目标的数字直接比较强弱。

## 二、首次数值计算之前冻结的预测协议

[正式 R073 E2 条件个人预测协议](../../protocols/R073_HUMAN_IPD_LAGGED_SOCIAL_MEMORY_LOSO_2026-10-17.md) **先于首次R073真人模型拟合**提交Git commit `8f8e5451692065f1b62db0338bc5b4fa5def486f`。固定12场次(FP6、SP6)、188名受试者(FP92、SP96)、全部18800条真实本人 C/D 选择；统一只对每位 `t=3..100` 的98次目标评估共 **18424条个人二元事件**。使用上一轮同一人的 `own_{t-1},opp_{t-1}` 和上上轮 `own_{t-2},opp_{t-2}`，从不读取当轮对手或当轮真实结果作为特征。**SP上一轮的对手可能与本轮完全不同，故它是上一段社会反馈，不是当前潜在对手“已知信誉”。**

严格12折Leave-One-Session-Out：每次整场次留出，**只用剩余同处理5个场次**的本人 t3..100 值训练；无同一人的行动进入训练/测试两侧。每轮预测允许已实际经历的过去自己及前一对手动作，故是 teacher-forced、短期条件预测，不是只看实验第一轮后100轮自主递推的开放循环长程演化模拟。

七个**结果前固定**竞争基线：
- M0 同处理其它5场的训练期总体合作先验 `p0`。
- M1 仅前一轮自己行为 P(C|own_1)，2个状态。
- M2 仅前一轮对手行为 P(C|opponent_1)，2个状态。
- M3 两者上一轮联合 P(C|own_1, opponent_1)，4个状态。
- M4 两者两轮联合 P(C|own_1, opponent_1, own_2, opponent_2)，16个状态。
- M5 固定带0.05误差的TFT（复制上轮对手的C/D）。
- M6 固定带0.05误差的WSLS/Pavlov（上轮CC或DD下一次C，否则D）。

M1–M4 所有条件概率按相同**提前固定不经真人数据调参**的平滑 `alpha=20` 与同处理训练先验：`(train-state C人数+20*p0)/(train-state人数+20)`。未出现的状态直接用训练先验。M5/M6并非作者原HMM回收个人策略，不拟合真实行为人的稳定类型。主要指标 **每场内部的个人Brier均值，12个场次再等权平均**，并另报告六个FP与六个SP的子集均值；log loss作为第二损失。主对照 `M3−M1` 检验对手最近行动带来的**条件预测增量**、`M4−M3` 检验额外前前一轮双方历史的增量（同一模型，不预设任何比较肯定成立）；也保留M0、理论模型的所有负结果。**不把18424个目标视为18424独立分组实验，也不做场次仅6个的未预注册显著性p值。**

2. `M4−M3` 12场等权下降 **0.004212**（0.124758→0.120546）。FP **4/6改善、2/6变差**，每场平均 `−0.002307`；SP **6/6改善**，平均`−0.006116`。这揭示“更多上一轮社会反馈”不是普遍/必然优越，且额外复杂度16态即使有平滑仍可在一些场次恶化成绩。

4. **TFT与WSLS“硬”理论策略不是同一个由数据训练的个体概率模型**。固定0.95/0.05且不随人的异质性或实验场次调整，TFT总体Brier0.253900低于吗？**高于**M0的0.226411，因此总体比仅处理平均更差；但TFT在FP六场6/6好于M0，SP六场0/6好于M0。WSLS总体0.465069，在两个处理都表现很差；不能以此否定真实人可能采用TFT/WSLS近似行为，只能拒绝“所有人在所有轮严格按单一理论策略且错误率固定5%”这个强基线的概率预测表现。

## 四、对心理史学模型整合的价值与科学限制

本轮第一次用与社会反馈和时间深度语义相符的**真实逐人选择**数据在现有研究库中做完整同风险集预测，为微观层模型提供可复验的条件性事实：**按固定平滑和12整场留出，自己上一轮与上轮对手动作合用能改善预测，再补两轮可能进一步改善。** 这一结论**只是已观测短期历史对下一次个人行为的统计预测能力**；不能把相邻历史当作“心理记忆器官的因果机制”，也无法判明其究竟由对对手的信任、过去收益/赢输、简单动作惯性、实验反馈、或其他不可观测状态导致。尤其固定对手 vs 打乱对手含不同互动组织形态，不能称“一般历史社会制度”的观察。

长程社会演化尚缺群体规范积累、公开制度信息的可信度、跨代文化复制、迁移与第三方声誉展示；本真人实验只含**前一轮实际对手动作**而没有全面公共信誉或机构惩罚制度，不是对 R072 的评判伦理规范直接验证。作者原始HMM未复现；并非投影到另一个国家或另一种文化的E3。作者投稿版与Dryad最终版原件相同仍未知，亦不宜未经许可公开匿名原始CSV。

**下一科学行动**应优先对**独立人类来源/另一实验场次之外的群体**做相同冻结特征/误差标准，而非先为R073创造新复杂模型去拟合已见结果。当前证据在有限内部E2层足够形成明确模型竞争反例，PESEN v0.1继续FROZEN，不能据此升级原创心理史学模型的广域历史预测合法性。
