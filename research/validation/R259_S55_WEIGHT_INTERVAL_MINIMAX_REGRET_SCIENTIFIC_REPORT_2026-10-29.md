## 数学对象

令 `L(d,λ)=λ f1(d)+(1−λ)f2(d)`，`m(λ)=min_a L(a,λ)`。对全权重区间 `[0,1]` 与中心区间 `[1/4,3/4]`，分别求 `min_d max_λ (L(d,λ)−m(λ))` 和 `min_d max_λ L(d,λ)`，另列名义 `λ=1/2` 最优方案。全部使用精确有理数，平手全部保留。

对每个固定方案，遗憾是有限个仿射函数的逐点最大，因而是凸函数；在一维闭区间上的最大值在端点可达到。加权损失自身为仿射函数，也在端点取最大。因此端点精确计算足以完成该冻结问题。B轨另用全部方案两两加权成本直线交点与区间端点构造分段包络，独立核验全区间极值。

## 九世界精确结果

下表每项为 `最大遗憾最小值 / 全部最优方案`。

| 人工世界 | 全区间 [0,1] | 中心区间 [1/4,3/4] |
| --- | --- | --- |
| LINEAR_FIVE_ALL_SUPPORTED | 2 / C | 1 / C |
| CONCAVE_THREE_UNSUPPORTED | 3 / C,D | 7/4 / C,D |
| DOMINATED_EXTRAS | 2 / C | 1 / C |
| OBJECTIVE1_MULTIPLY10 | 4 / A | 0 / A |
| DUPLICATE_TIE | 2 / C | 1 / C |
| STRICTLY_CONVEX_DISCRETE_FRONT | 2 / C | 3/4 / C |
| OBJECTIVE2_MULTIPLY10 | 4 / E | 0 / E |
| REVERSE_LABELS | 2 / C | 1 / C |
| LINEAR_COST2_STEEPER | 3 / D | 1 / E |

**发现1：极小最大遗憾可以选择任何连续加权求和都无法支持的 Pareto 方案。** 在 `CONCAVE_THREE_UNSUPPORTED` 中，原 R259 已精确证明 B、C、D 均为 Pareto 有效，且连续加权支持区间为空。全权重区间的极小最大遗憾方案为 C、D，最优值3；中心区间仍为 C、D，最优值7/4。这些方案的身份由完整原成本表决定。两种决策规则解决不同优化目标，因此不会产生数学矛盾。

**发现2：最大遗憾与最坏加权绝对损失可以选择不同方案。** `LINEAR_COST2_STEEPER` 在中心区间的极小最大遗憾唯一方案为 E，最大遗憾1；极小最大加权损失唯一方案为 D，最坏损失11/4。此时 E 的最坏加权损失为3，D 的最大遗憾为5/4。把两种目标都叫作“鲁棒最优”会掩盖实际偏好假设。

**发现3：权重范围改变可改变稳健决策。** `LINEAR_COST2_STEEPER` 从全区间的 D 转为中心区间的 E。所有九世界、五方案的最大遗憾及最大损失在全区间均不小于中心区间，完整检查通过。目标数值缩放仍影响相同名义权重的含义。
