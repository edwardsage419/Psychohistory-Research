## 4. 本轮新增的研究权重与逐项剔除敏感性

把每项研究自己的严格会话等权 Brier 差记作 `d_s`。只为描述四项既有结果的跨研究稳定性，计算等权 `mean(d_s)`，以及每次删除一项研究后对其余三个等权。绝不把研究数为四当作足以检验普遍性或支持独立同分布显著性推断。

| 被剔除研究 | 余下三研究的 M3−M1 | 余下三研究的 M4−M3 |
| --- | ---: | ---: |
| R073 | −0.027414482 | −0.003721688 |
| R074 | −0.022922413 | −0.006182371 |
| R075 | −0.020855071 | −0.000986583 |
| R077 | −0.020490603 | −0.004485971 |
| **四研究等权** | **−0.022920642** | **−0.003844153** |

第一条主对比 M3−M1 在所有四个研究上为负，因而**对这四个已经观察到的宏差使用任何非负且和为 1 的权重**，加权结果仍严格为负，其所有可能值精确位于 `[−0.030210760470721517, −0.009439123715841404]`。这是四个已归档数字的凸组合性质；并不能保证未来第五研究同样为负。

第二条 M4−M3 的任意非负加权宏差可能处于 `[−0.012416864447856633, +0.003170501040435799]`，因此**改变研究权重可以推翻等权总体改善的方向**。严格可构造反例：令 R074 权重为 w，其余 R073、R075、R077 各为 (1−w)/3，则

[
d_{M4-M3}(w)=w(0.003170501040435799)+(1-w)(-0.006182371083731796).
]

当 w 超过 **0.6610131093053971**，加权 M4−M3 变成正值，说明增加第二轮历史的预测误差反而更高。这个 66.1% 门槛是条件性的**数学敏感性阈值**，没有被宣称为任何真实总体的适当研究权重。

四个逐项剔除计算中 M4 均为负，仅表明在“余下研究等权”这一限定情形下，单独剔除一个研究不足以改变其方向；它无法消除 R074 的真实性或决定模型在未来新实验中的得分。
