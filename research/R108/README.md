在原个体模型评价前冻结三轮来源结构调查：B0真实**1804条五字段记录**（[机器收据](R108_PHASE_B0_LIVE_CI_2017_UK_ORIGINAL_CSV_ANONYMOUS_ROW_WIDTH_STRUCTURE_ONLY.json)，10 synthetic，未读取个体单元格）；B1真实五列**有限匿名取值类型**检查（[机器收据](R108_PHASE_B1_LIVE_CI_ORIGINAL_2017_FIVE_COLUMN_ANONYMOUS_CELL_TOKEN_TYPE_CENSUS.json)，18 synthetic，首次一个仅合成fixture错误保留，源真实行为值未输出/未建模）；B2真实数值结构（[机器收据](R108_PHASE_B2_LIVE_CI_TRUE_2017_ORIGINAL_SIX_300_BLOCK_CONDITION_SOURCE_ELIGIBILITY.json)，12 synthetic、[Actions run 39131372988](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/39131372988)成功），准确确认**前4行非数值前言，随后6组各300轮，第一槽在每组严格1..300，后两编码槽分别只有2种与3种编码且组内不变，恰好六个不同组合，末两列大量连续小数**。该结构可能对应原作者论文的2种收益制度×3种性别组合，但原附件首表头为4个空列名，不存在已核验的人号、对手号与真正采集session码本，**不得把6个条件序列叫6个独立真人或6个独立场次**。

当前源可用于描述性条件时间曲线探索（须另行冻结问题和检验），**不能作为R073/R106逐人上轮自己+真正对手行动的合法留出E2样本**。人级模型新增评分0，不能算模型阴性也不能算独立正面复验。不以条件均值预测的好坏推断心理模仿或真实人际因果。下一方向R109优先不同来源、公开出版社MD5、真实逐人×伙伴×回合×实验场次的真人配对博弈，冻结合法相同预测收缩/伪配对负对照后才看行动结果。
