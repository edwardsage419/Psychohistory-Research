# R188：六群组人工数据的固定效应得分抵消与稳健方差退化

日期：2026-11-14。状态：已完成内部人工E1数学复算及本地双模式测试。本文件为**事后新增诊断**，不改变 R188 原研究的冻结协议、原先的研究级结题、原239目录级验收或证据等级。

## 研究起点及去重

核对正式 main、原239目录、五条已有自动工作流及9项Codex草稿PR。科学收尾自动轨道当前处理R183源码来源身份；R主线处理R132历史认证；真实数据轨处理R073数据资格。本项选择此前未覆盖的 R188 群组稳健方差退化问题。原R188已对180个人工世界、8640行数据、720次准去均值回归完成有界E1验收，本次不重复计为新成果。

来源固定：原R188程序 Git blob 40a467a519f97baae4cb6677b049fe2c448d692f，结果 JSON Git blob 9d57c24f6327f1e0ce5c83cba4d55174bded1292。原设计每世界6群组，每组8行，组内暴露数依次为 BALANCED (4,4,4,4,4,4)、WEAK (2,2,4,4,6,6)、STRONG (2,2,2,6,6,6)。y=a+bx+c*xbar_g+epsilon，群内每个暴露细胞有相等数量的 +e 与 -e。

## 方法

组内中心化变量 x̃=x-xbar_g，ỹ=y-ybar_g，S=∑x̃²，FE斜率 βhat=∑x̃ỹ/S。残差 uhat=ỹ-βhat*x̃，六组得分 U_g=∑_{i∈g} x̃_ig uhat_ig。

定义三个未做有限样本自由度修正的描述性方差计算：

1. 群组稳健 CR0 = (∑U_g²)/S²。
2. 观察级稳健 HC0 = (∑(x̃_ig uhat_ig)²)/S²。
3. 传统同方差 FE 方差 = SSE / [(48-6-1)*S]，其中六组截距及一个斜率合计使用七个参数。

本源中每组每个细胞的误差和严格为0，所以 βhat=b，所有 U_g=0。对三种设计 S 分别为12、10、9；SSE=48e²。因而 CR0=0、HC0=e²/S、传统同方差方差=48e²/(41S)，为**精确有理数代数恒等式**。

## 实际执行

本地从原R188生成公式重新构造180世界共8640条人工记录，用 Python 标准库 Fraction 逐行计算全部三类方差、六组得分、SSE和FE系数，逐项独立核对解析公式。180/180世界CR0精确为零；e>0的120/120世界HC0严格大于零，其余60世界e=0，HC0=0。

对每世界六次依次剔除一个完整群组，总计1080次斜率仍是原 b。对每世界完整枚举462种六群组有放回重抽样的无序组成，合计83160次，斜率同样恒为 b。462是6组抽取6次的不同多重集合个数，带顺序抽样共有6^6次，不能混写。

负对照：把每世界第一条响应确定性增加1/16。此时 βhat 的增量恰等于 (1/16)*(xfirst-xbar_g0)/S，180/180世界的CR0均从零变成严格正。固定 STRONG,a=0,b=1/4,c=-4,e=1/4 示例的S=9、SSE=3、CR0=0、HC0=1/144、传统同方差方差=1/123；定点扰动后βhat=143/576、CR0=5/1990656。

测试：本地 Python 15项单测普通模式全部通过，15项优化模式全部通过。首次单测的负对照期望误将斜率偏移设为1/192，实际正确值为1/576，已修正单测预期并保留首次失败说明，未改变原人工模型和算法。实际CI未触发。完整逐行Python源码、180世界详细 JSON、测试日志及机器收据在本轮可下载科研包中。此GitHub目录的Node标准库证书另以独立解析路径，直接校验原R188 JSON Git blob并逐世界输出精确数据，补充原始记录身份验证。

## 证据边界与科学意义

这是一项人工确定性设计中的代数负对照，没有定义任何重复随机抽样机制或真实群组行为。CR0=0 不等于真实估计不确定性为零，更不能推导群组稳健估计在一般现实研究中无效；六群组的小G环境本身也不支持未经谨慎修正的渐近统计推断。组内残差正交是此人工机制被刻意构造出来的，重抽样无法凭空产生从未出现在六群组中的组内斜率差异。
