## 算法及证明
令 G=(L,R,E)，完整世界是覆盖所有左节点的注入匹配。先用增广路径求最大匹配 M。若 |M|<|L|，从全部未匹配左节点出发，沿左至右候选边和右至左已匹配边求闭包 S,T。最大匹配无可增广路径，T 的所有节点均已匹配且其匹配左节点均在 S；S 另含至少一个未匹配左节点。因此 T=N(S)，|S|>|T|。该 Hall 缺额证书证明有限完整图无世界；未完整图只报告 UNKNOWN，不发布冲突证书。若饱和，对每条边 (i,j) 删除左 i、右 j 后再求匹配，能饱和剩余左节点当且仅当该边属于某完整世界。证明为从原世界删边和向缩减世界添加边的双向构造。仅完整图下一个左节点的支持集大小为一才是有限世界内强制关联；不意味着用户意图、实际证据或写入资格。

时间：DFS增广最大匹配 O(|L||E|)；逐边重新匹配上界 O(|L||E|²)；闭包实现逐轮扫描；递归深度随左节点数增长，当前程序仅小图实验，不是面向任意规模或攻击输入的生产实现。可后续研究交替路径/SCC优化、显式多容量和未关联选项。完整图之外的未知边可能恢复冲突或产生替代匹配，因此不完整图只能报告已存在完整匹配的正支持；若图内所有边已具真实资格且固定组和容量合同有效，则添加边不消灭已找到世界。该单调性不适用于未知分组、未确认容量或后续证据撤回。

## 核心复算说明（摘录）
```python
def maximum(rows):
    owner = {}
    def visit(i, seen):
        for j in sorted(rows[i]):
            if j in seen:
                continue
            seen.add(j)
            if j not in owner or visit(owner[j], seen):
                owner[j] = i
                return True
        return False
    for i in range(len(rows)):
        visit(i, set())
    return {i:j for j,i in owner.items()}

def edge_support(rows):
    if len(maximum(rows)) != len(rows):
        return None  # full implementation constructs Hall witness
    return tuple(tuple(sorted(j for j in row
        if len(maximum([r-{j} for k,r in enumerate(rows) if k!=i]))
            == len(rows)-1)) for i,row in enumerate(rows))
```
