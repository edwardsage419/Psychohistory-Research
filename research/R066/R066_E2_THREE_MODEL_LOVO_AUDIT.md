# R066：三类意见动力学模型在真实村庄态度数据上的整村留出预测

日期 2026-10-16。结论等级 **E2 / 有限真实数据内部整村留出**。这次试验提供有来源保障的回顾性描述性模型评分，**没有**证明任何一种模型为真实社会影响的因果机制。模型预测实验的事前冻结协议在 Git commit `85b8abb398f2e4cc060b6e4b36dc6880893455a1`，与真实首次结果分离。

- 关键独立源对照：[原作者 R vs Python 逐边验证](R066_E2_AUTHOR_R_CORE_EDGE_PARITY_AUDIT.md) GitHub run [38865507356](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/38865507356)，16 村四类有类型家庭边 14,767 条、两个边集合差为 0；关系类型并集 8,659 条独立家庭边。这个结果只验证作者 R 的 `make_el / convert_to_hh` 核心边构造，完整作者 igraph 图分析并未重跑。
- 本次重新验证三份真实来源并确认：2125 家庭/访谈行，基线与末次六题量表均完整的 **1872** 行，干预后即时六题完整 **905** 行，有 144 个网络节点既无完整基线也无即时测量，按冻结规则使用**该村已观测基线均值**插补。插补绝不使用末次意见。
- 原作者六题 1–5 量表直接加总为 6–30，再映射到 `[0,1]`。起始状态对即时完整者使用已观测即时六题结果，对其余人使用基线（如两者均无，则按上述村内基线平均）。**预测时点位于干预即时观测之后、二三周末次之前**；不得称「完全用基线预测处理响应」。

## 二、完全冻结的参数与留出

按照 [真实三模型协议](../../protocols/R066_E2_THREE_MODELS_LOVO_2026-10-16.md) 采用**整村留出 16 折**，每折用另外 15 村选择模型族内网格参数和一个单独的跨训练村共同加性 `δ`，用 16 个留出村作为评估。所有评估村末次意见在该折选参/拟合中不可访问。指标为 `[0,1]` 规范态度上的 MSE，主要指标对 16 村等权，次要指标按 1872 名有完整两波的家庭行加权。

- Persistence：保持预测起点不变，只拟合公共漂移 δ。非网络基线。
- DeGroot：作者来源四类家庭关系并集构建无向邻接，同村邻居同步等权平均；孤立节点保持当前状态；训练候选更新轮数 1、2、4。
- Friedkin–Johnsen：同一真实 W，`α∈{0.25,0.5,0.75,1}`、轮数 1、2、4，按 FJ 与起点意见锚定公式同步迭代。α=1 等于相同轮数 DeGroot。
- HK：经典同村**全连接**有界信任，`ε∈{0.05,0.15,0.30,0.5,1}`、轮数 1、2、4；HK **并没有用已测家庭边 W**，其信息结构与 DeGroot/FJ 不等价。保留它是为了比较机制族，而不是公平的同网络影响估计。
- 所有四种方案都只利用训练村末次评分拟合各自的一个公共漂移 `δ`；不得为测试村使用它自己末次信息。训练网格参数若同分，按协议先列顺序选取。

## 三、已完成真人数据计算与关键结果

[GitHub Actions run 38866210819](https://github.com/edwardsage419/Psychohistory-Research/actions/runs/38866210819) 两项作业全部 `completed/success`，17 项 synthetic/隔离反例测试 PASS。真实源作业运行了 16 村全折，程序 [r066_three_models_lovo.py](r066_three_models_lovo.py)，完整匿名聚合数值永久保存 [R066_E2_THREE_MODEL_LOVO_RESULTS.json](R066_E2_THREE_MODEL_LOVO_RESULTS.json)，细节原始 artifact `12031028109`。

训练村内选出参数的 16 折频率：DeGroot `k=2` 全 16；FJ `α=0.75,k=2` 3 折、`α=0.75,k=4` 13 折；HK `ε=0.5,k=1` 全 16。四类各折训练得到的公用漂移 δ 都来自训练村，按来源档案报告其最小/最大值。

**可支持结论：** 在此回顾性固定来源、条件于即时测量的整村内部预测下，三个动态机制族的损失均低于简单双时点坚持性基线。宏观村等权指标中 HK 最低，FJ 仅高 `0.0000670953`（平方单位）；按个人数加权的 MSE/MAE 则 FJ 略低。这个指标依赖 16 个村庄，**尚无折级差异置信区间或新独立数据**，也未建立 DeGroot/FJ/HK 的真正机制因果可辨识性。三类模型都对本实验的异质干预与社会环境做了重大简化。

## 四、科学与后续边界

- 该真实数据来自同一实验的 16 个村庄；留村不等于新的独立实验/国家，**E3 OPEN**。
- 论文在 2021 与 2023 年分两批村庄实施干预、对约 40% 家庭随机施加处理；处理暴露和即时反应、各村漂移差异、关系形成选择性均可影响成绩 <Link url="https://doi.org/10.1017/nws.2026.10038">作者论文</Link>。
- 全连接 HK 与真实 W 的 FJ/DeGroot 在信息假设上不同；不同网格复杂度及训练村模型选择也影响比较。最低 MSE 不能升级为「HK 优于 FJ 的心理机制已确立」。
- 初次简单 ego ID 键联结已 fail-closed，后续作者家庭网络核查另行 pass，不能改写历史失败证据。完整原作者 igraph 回归分析仍 OPEN。
- 后续独立研究可增加**留出村为单位的配对不确定性**、预先冻结的新县/村样本、网络不存在的对照和对实验即时反应的冲击结构。不得根据本次排名偷偷改换模型、分折或来源。
- 尚未验证模型中间状态、心理认知机制与长期制度演化/历史结果的跨尺度预测。**PESEN v0.1 保持冻结**。
