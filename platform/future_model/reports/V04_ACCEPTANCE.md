## 真实浏览器闭环

Chromium 在同源环回服务输入开放式虚构职业问题，采用候选片段并确认目标、期限、候选和工时底线。工时上限修改后可行集实时更新。缺少共同效用尺度时联合计算明确拒绝。补全条件后，C034 初始效用差为 `[0.02, 0.055]`，调整权重后为 `[-0.015, 0.055]`，再加入评分误差后为 `[-0.075, 0.115]`。图表同步更新。新增无概率情景后，两项方案的最坏后悔值为 `0.35` 和 `0.40`，界面同时保留其他规则的竞争结果。

测试通过显式授权保存两版决策，模拟行动及合成回访，再导出经签名的记录。临时实验中移除个人内容库，确认预览阶段未新建文件；执行恢复后，两个原始快照、行动和回访可读，旧分析状态为 `RECOMPUTE_REQUIRED`。撤回再授权后，同一备份无法被恢复，旧授权访问受拒。测试同时检查 390 px 窄视口、三代科研导航、同源请求和浏览器页面错误。 [Chromium 收据](v04/BROWSER_RESULTS.json) · [可复现测试脚本](../scripts/browser_v04.py)

## 失败记录

| 阶段 | 观察与处理 |
| --- | --- |
| 基线初次执行 | 默认命令沙箱下，旧版 Starlette 测试客户端的 AnyIO 入口等待。保留首次未完成状态，以现有作用域内的环回能力复跑完整测试并通过。 |
| 评分集成 | 首次完整集成运行揭示了评分缺口字段缺失与期间未校验。补齐诊断、逐目标期间和跨目标共同期间校验后复跑。 |
| 接口与构建 | 备份测试初稿误将既有科研备份目录当作 ZIP，已按真实目录契约复核。首次开发中的构建尝试遇到尚未写入的样式文件，整合后生产构建通过。 |
| 记录与恢复审查 | 复现评分图表中的整数值浮点在浏览器序列化后破坏旧签名。签名改为绑定精确文本，复测正常导出和恢复。另复现旧修订选择映射至新修订、已确认来源被重写及同记录数量下内容损坏，分别通过修订绑定、原文和理解收据不变及账本摘要校验修复。 |
| 调度审查 | 复现同指标冲突区间的误接受、缺失门控结果导致后端异常、方法互相污染状态。修复冲突区间判定、门控契约验证和执行上下文隔离。增加不合规派生结果内容失效和重复回访重试的测试。 |
| Chromium 联调 | 初次开发脚本定位和启动路径曾失败，改为语义定位、正确模块路径和独立临时数据根后复跑完整流程。 |
