## 原生执行

`DecisionHubV05().registry` 登记了全部 15 项历史身份。基础 `default_registry()` 包含其中 8 项。7 个扩展方法均以 C028 `1.0.0` 为执行前置。时机方法使用结构性可行集，其余扩展方法使用当前可比较集。五个方法定义模块的实际字节与固定索引一致，15 条动态描述的来源、版本和前置依赖与索引逐一比对。

每个原生方法至少检查合法输入、缺项、无适用范围、语义异常和一个边界。合法和边界输入实际调用 `validate`、`execute` 与宿主 `run_method`，共 75 个方法与场景组合。C028、可比性和 Pareto 对部分缺项或口径异常保留局部 `UNKNOWN` 或 `UNRESOLVED`。其余方法的对应夹具由验证器拒绝。另用 `DecisionHubV05.analyze` 对 15 个方法逐一执行正向 *结构化* 入口。硬约束由 `<=10` 改为 `<10` 时，恰好等于 10 的方案全部被拒绝，14 个后续方法均未执行。

| 方法 `@1.0.0` | 算术参照、正向与边界 |
| --- | --- |
| `c028_interval_feasibility` | 数值 10 对 `<=10` 确定通过、对 `<10` 确定失败。量纲错误和无测量保留 `UNKNOWN`。 |
| `comparability` | 两方案 × 两目标为 4 行。单位失配和得分缺项保留 `UNKNOWN`。 |
| `pareto` | 一个目标优、一个目标劣时保留双方，两个坐标相等时为 `EQUAL`。 |
| `weight_sensitivity` | 直接代入权重端点的差区间为 `[-0.2, 0.1]`，等得分时差为 0。 |
| `c034_joint_robustness` | 枚举指定矩形得分端点和权重端点得到 `[-0.22, 0.1]`，等点值时差为 0。 |
| `C029` | 逐情景取最优效用并减去方案效用，A、B 的最大后悔值分别为 4、6。等点值时均为 0。 |
| `C030` | 枚举 4 个效用单元的全部端点组合，A、B 的最大后悔值界分别为 `[2,6]` 与 `[4,8]`。 |
| `C031` | 三方案尖锐误差半径为 `0.75`，等号处显式构造同后悔值见证。确认时机且第三方案可用性未知时，该方案留在结构可行集但退出当前比较，按余下两方案重算阈值 `0.25`。 |
| `voi_point` | 枚举 4 个确定性信号策略。点先验下净值 `0.4`，调查费用 `0.9` 时净值为 0。 |
| `voi_oracle_bounds` | 两端先验上对四策略直接求最大，所选区间内同一规则最优，净优势界为 `[-0.14,0.94]`。 |
| `voi_fixed_policy` | 将事前策略代入两端先验，净优势界为 `[-0.14,0.94]`。 |
| `voi_maximin` | 四策略分别求两端先验的最小净优势，最大值为 `-0.14`。 |
| `voi_randomized_certificate` | 在所选夹具上确定性下界与最优响应上界同为 `-0.14`。 |
| `timing_actions` | 无概率逐情景计算，B 等 0.25 天的好情景效用为 `10−2×0.25=9.5`，严格截止等号处为 `EXPIRED`。 |
| `timing_investigation` | 调查较立即行动的毛优势 `0.675`，费用 `0.5` 时净值 `0.175`，费用等于毛优势时净值为 0。 |

## 隔离登记

`decision_candidates.py` 通过独立的 `CandidateRegistry` 登记 C035、C036、有限期鲁棒长期规划、账本驱动有限情景规划及 R258。登记版本绑定仓库路径和 Git blob，许可字段为 `UNVERIFIED`。每项记录适用性、输入输出、公式、基线、失败例、复算入口及欠缺的准入条件。可按精确版本查阅，也可并存和重新选择旧版。五项全部为 `NOT_ADMITTED`，执行权限 `NONE`。测试验证了与原生 `DecisionRegistry` 的双向类型隔离、修改返回元数据不会改写登记、精确版本重复和非固定版本被拒绝。这里只登记候选元数据，研究算法执行、训练、实际许可审查及独立准入均待执行。
