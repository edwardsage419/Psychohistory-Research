# v0.5 智能决策中枢第二阶段

开发基线为 `f6115556`，包含 v0.4 合并提交 `2ecc6433`。本次按规程 v3.1 交付同一个产品版本。状态、计划、方法调度、工作台、隐私及验收一起交付。

## 设计选择

沿用现有环回服务、Python 决策中枢、React 工作台和 SQLite。新增 v5 API 与 CLI 子命令，保留 v4 入口用于旧记录及回归。计划模块读取问题状态和方法审计并给出可解释的下一步。通用步骤先完成理解确认和硬约束筛查，再根据实际证据使用可比较性、情景后悔、有限信息价值和行动时机模型。

扩展采用可选方案模块及稳定方法卡。同一个输入协议覆盖多领域，UI 根据追问和用户意向揭示可选分析。一个总模型会把几种不兼容的假设混在一起，固定调查表也难以处理与调查无关的提问。当前默认使用可运行的确定性规划，未来可以注入已授权的候选理解或证据适配器并逐项确认。

信息价值与时机模型按实际有限联合空间复算。明确区分点参数重优化、固定策略在全域保证及最坏值目标。不清楚联合分布时只给有证据的条件性比较。行动记录独立于建议和计划。偏好更改附于复盘并单独采用到未来；旧快照沿用原确认时点。
