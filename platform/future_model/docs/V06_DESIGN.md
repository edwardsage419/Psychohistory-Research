# v0.6 对话决策设计

开发基线为 `e3dd603b`。现有 v0.5 确定性引擎、同源 API 与私有记录保持兼容。PR #59 和 #60 作为代码来源，保留各自 Draft。复杂分析继续复用 v0.5，普通入口为会话。

## 选择和边界

客户端以短问题、一个优先追问和明确核对组织交互。服务端在有限期内保存临时会话与证据修订，并以会话修订拒绝过期提交。只有核对后的输入进入 v0.5 数学门控。每轮清除旧派生结果。可选 Ollama 只给出从原文定位的候选线索，建议的方法仍由验证后的注册表调度。模型不能确认事实、增加概率、保存数据或授权行动。

优先复用 v0.5 模型和备份契约，避免第二套数学实现。移动端继续使用 PR #59 的离线模型、共享契约和私有存储。iPhone 与 Mac 真机资格独立于浏览器、模拟传输和托管 macOS。

## 验证顺序

核对基线和研究准入。实现证据、语言、会话和渲染入口，分别测缺失、冲突、修订、故障与输入伪造。以冻结的虚构跨域文本验收首答，另用程序及浏览器场景验证计算、保存和恢复。复跑先前版本，收录数学复算、真实设备限制、独立验收交接及回退。完整候选进入独立 Draft。
