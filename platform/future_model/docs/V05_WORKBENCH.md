# v0.5 主动决策工作台

## 启动和使用

在 `platform/future_model/` 使用 Python 3.12、Node 24 和项目锁定依赖。

```bash
bash scripts/install.sh
bash scripts/verify.sh
bash scripts/run.sh --data /workspace/psychohistory-data serve --port 8765
```

以本地令牌连接 `http://127.0.0.1:8765/`，进入「个人决策工作台」。研究页保留原有机制、实验和科研版本。v0.4 兼容工作台可由 `/?workflow=v04` 访问。

1. 用自然语言说出实际选择。原文保留，明确措辞提供待确认片段。核对目标、方案、底线、时限和哪些情况会使方案失效。
2. 查看主动追问。影响可行性的事实优先，补齐来源和可比指标。对已确定被其他底线排除的方案，当前可以暂缓核实不影响结论的值。放宽底线后系统重算这项判断。
3. 对确实涉及调查或等待的选择，按展开的相应问题填写成本、时间和后果。成本和效用需可比较。缺少可靠概率时使用有依据的情景；概率数值需提供来源。可折叠方案分组，模型仍使用完整的底层候选集。
4. 比较立即行动、等待、调查及维持现状。核对模型条件、截止边界和可能使建议反转的因素。修改输入后检查新修订的图表和证据。用户决定偏好和最终选择。
5. 授权后可保存事前偏好和分析。未来选择或计划与观察到的行动分开。实际观察只归于已选行动。复盘可追加后来证据、当时流程质量及最新偏好，随后单独确认一版偏好用于未来分析。采用后的版本需用户主动在新问题中引用。
6. 共享设备上结束会话，或清理当前未保存的输入。结束会话清除应用当前令牌及临时视图，已明确授权的历史需要再次连接读取。系统和浏览器可能有自己的页面快照、缓存、自动填充或下载副本，应用无法清除这些外部内容。导出是带签名的明文 JSON，请由授权人保管。

## 证据和方法契约

`/api/v5/decisions` 提供 `/start`、`/analyze`、`/models` 和原有个人记录路径。新增 `/preferences` 接受当前 `epoch`，`/adopt-preferences` 另需 `decision_id`、从 1 开始的 `review_index` 及显式 `confirmed:true`。v0.5 的 `/review` 可带 `hindsight`，旧字段语义原样支持。CLI `decision-v05` 使用相同 JSON 契约，原 `decision` 保留 v0.4 行为。

```bash
printf '%s\n' '{"question":"我该现在参加虚构课程，还是等下一期并保留资金？"}' |
  bash scripts/run.sh --data /workspace/psychohistory-data decision-v05 start
bash scripts/run.sh --data /workspace/psychohistory-data decision-v05 models
```

| 对象 | 版本和边界 |
| --- | --- |
| 决策输入 | 继承 v0.4 字段及原文收据，`workflow_version` 标记 0.5.0。新增信息模型、时机、偏好、用户意图、证据和计划选择。保存前由后端重算，拒绝客户端计算结果。 |
| 规划 | `plan.steps` 表示当前流程，`plan.items` 包含问题、影响理由、字段目标与证据状态，`plan.can_run` 记录已发现的可运行方法。优先级由可行性和方法适用条件确定，没有真实信息价值单位。 |
| 模型 | 复用 `decision_registry.Method`，可声明精确的 `model_id@version` 依赖。中枢先验证硬约束和当前时点可用性，再按拓扑顺序执行。时机模型保留基于硬约束通过的方案，逐时间重新判断。缺失、运行失败或拒绝的前置方法不会向下游提供结果。方法收到独立上下文和已成功的已声明依赖结果。 |
| 证据 | 证据条目含用户声明的事实、估计、假设、合成或未知，以及来源、适用范围及用户核对状态。显示的用户核对不等于联网验证。 |
| 未来适配器 | `decision_extensions.DecisionAdapter` 声明能力、身份、版本、隐私范围、最大输入、已核实费用约束和超时。逐次批准固定适配器版本和相同的最小查询，外部模式需单独许可。错误、超时、非法输出或缺许可返回明确状态。候选建议不可直接写入决策状态。 |
| 行动 | `intended_option_id` 和 `plan_note` 为未来计划。API `/action` 只记录已发生的行动及所指的保存修订。当前没有外部执行能力或执行授权入口。 |
| 隐私 | 决策根与科研根分离，沿用原签名和当前授权账本的信任要求。保存、回放和恢复均检查授权，旧授权不能复活。新版本偏好和复盘不会覆盖原始快照。 |

当前没有经核实并启用的免费外部推理或检索服务。实际使用确定性语义线索、按证据状态组织的追问和已有确定性模型。使用者可提供来源及适用范围供确认。

## 数学口径

### 有限调查

同一问题的状态、信号及效用使用有来源的有限矩阵。无调查基线对每项可行动作算 `Σ p(s) u(a,s)`，取最大值。调查计算每条正概率信号的联合期望 `Σ p(s) p(z|s) u(a,s)`，只在该信号下的可行行动中取最大后求和。减去基线和同量纲成本得到净增量。概率为零的信号对总值无贡献且不产生行动建议。只有可以忽略信号、行动范围相同的条件下，常规 EVSI 非负。

区间参数分析只在声明的可验证联合域和方法允许的规模内运行。逐参数重新优化的范围、实际统一固定策略的全域净增量以及可列举策略中的最坏值最优为不同指标。严格证书要求最坏净增量大于零。隐藏的依赖、未知成本、不同单位或超出精确算法的规模使用明确的限制状态。

### 时间、完成依赖和机会成本

时机模块以共同时间起点、单位和外部阈值比较每种行动路径。希望完成时间、预测完成时间、硬截止与已记录行动分开。可变可行集以实际阈值及是否含等号重算。等待及维持现状有自己的效用、机会损失、切换成本与条件。调查的概率计算按实际可观察的信息和完成时间枚举，支持直接联合分布或明确有依据的条件分解。仅有边际分布时，相关性未知，保留条件比较。可逆性由使用者声明并单独呈现；难以量化的损失可进入硬约束或情景说明。

### 许可和回退

用户当前授权期间，完整原签名导出及未撤回的原授权账本可验证恢复。v0.4 格式导出仍可由 v0.5 验证，新增复盘、偏好或 v0.5 快照时导出使用新的兼容版本。回退到 v0.4 时，它可读取原有历史，新增格式及后续修改请保留 v0.5 工具。按 [验收与回退](../reports/V05_ACCEPTANCE.md) 使用独立工作树或临时数据根，保留当前授权账本，不要将旧磁盘副本写回原目录。
