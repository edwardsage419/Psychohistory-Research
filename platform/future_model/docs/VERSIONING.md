# 版本兼容、迁移与回滚

平台 0.1.0；数据交换、适配器、快照和两个插件分别 1.0.0；合成协议 synthetic-paired-1.0.0；数据 generated-1.0.0。每次运行记录这些独立身份、源码哈希、Python 环境、输入、种子、事件、产物哈希及完整日志。科学运行禁止 `latest`。

插件注册键是 `(model_id, version)`；同名不同版本可以并存，同名同版本重复拒绝。适配器有独立版本，历史交换保留所用版本。快照包含模型版本、父哈希、分支、事件、环境和 RNG 状态；未知快照/数据版本拒绝，不悄悄解释为当前格式。

SQLite `PRAGMA user_version=2`。v1 的 assets(sha256,payload) 可事务迁移，新增 registered_at，建立任务/审批/版本表；迁移保留原 payload。未来 schema 拒绝打开。核心测试、迁移测试、恢复测试分别记录实际结果；不存在自动改写旧科研收据的迁移。

升级：先备份和校验，检出明确 Git SHA，按锁重建，运行完整测试与合成复算。失败则保留错误与原根，在新目录恢复此前已验证备份，再切换软件和数据路径。不要用 Git reset / 数据覆盖掩盖失败，不把回滚等同于删除审计历史。macOS 原生迁移/回滚实测未运行，NOT_RUN。
