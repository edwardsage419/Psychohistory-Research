# v0.5 独立科研验收交接

对象为通用中枢、有限调查、时机比较和个人复盘记录。开发测试与后续独立留出分开。开发团队已经读取的方法卡数值、`tests/test_decision_*.py` 的开发数据、`scripts/browser_v05.py` 的三个场景，以及本次代码审查反例均归入开发集。独立工作流另行生成、保管和执行未见案例，提交可复算结果和模型采纳判断。

## 待独立验证

| 范围 | 独立验收设计 |
| --- | --- |
| 通用和交互 | 任选未见决策领域，真实输入并分步补充。检验决定性事实与无效问题的区分、可逆筛选、模型选择理由及合理改动后的结果变化。 |
| 有限调查 | 独立枚举状态、信号和行动。核对零概率、无法行动、成本临界点、未知来源及上下界。将逐点适应、统一固定策略和有证明的随机证书分别做反例。 |
| 时间与依赖 | 独立构造同边际不同依赖的模型，验证不同动作集合、等号、机会失效、临界等待、显式兜底及未给届满后果的拒绝。 |
| 证据及公平对照 | 用声明尺度和同一候选集与忽略信号、立即行动、固定策略、旧 v0.4 的比较做对照。保留无改善和退步。研究结论不得据单个个人结果更新。 |
| 时序和隐私 | 验证角色偏好、行动计划、实际做法、事后证据、流程质量和观察分别保留。测试明确采用未来偏好、旧签名副本和删除撤回、环境重启及共享设备可见性。 |

测试应固定代码提交、数据来源、数学参照、日期和脆弱条件。结论分别登记数学复算、失败边界、软件/界面结果、独立科学准入及真实个人效果。不提供真实个人记录给独立验收或公开仓库。当前所有独立留出项为待执行。
