# v0.8 局部计算与联合情景接口

## 工作台局部计算

工作台先从会话账本投影当前已确认的方案与事实。全局仍有未决义务且上下文已确认时，可以单独展示两类结果。第一类由现有 C028 的区间比较得到，报告某方案违反某条已核对阈值的条件性证据。第二类计算同一指标、单位及时域下两个已确认点值的差额。结果包含方法版本、原文依赖和数据口径。

局部结果的 `authority` 始终为 `NONE`。完整分析、选择与计划继续使用原生筛查和授权。经用户确认且口径一致的实际值和同值估计同时存在时，底线投影优先使用实际值。不同值或不同口径继续由原账本冲突与不可比规则保护。

## 隔离候选的宿主合同

`psychohistory.decision_composition` 1.0.0 实现有限联合情景、预算续算与竞争模型覆盖。宿主可用固定输入调用以下入口。

| 接口 | 当前输入 | 当前输出 |
| --- | --- | --- |
| `prepare_join` | `CompositionScope` 以及阈值和收益两个 `GroupedPort` | 有界、不可变的内部计算计划 |
| `advance_join` | 当前宿主范围、内部计划、组对比较预算、宿主签名密钥及可选续算状态 | 条件枚举中的已通过、已失败、待计算及缺少证据的世界，并提供计数界与见证 |
| `compare_hypotheses` | 当前范围、明确的行动集合及范围内可能成立的模型假设 | 逐世界的共同最优和可能最优集合，以及缺失覆盖 |

宿主应先核对模型科学资格、来源、用途、单位、时间和约束口径，再创建共同范围。`CompositionScope` 绑定会话实例、修订、授权代次、证据代次、世界域身份和版本。每个端口另外携带方法与来源版本。同一端口中每个世界至多出现一次。阈值中的 `null` 表示在该情景无有限可行阈值，省略一个世界表示该端口缺少证据。相同情景内阈值和收益均有值时才计算。未获核对的完整域给出 `UNKNOWN_COVERAGE`。

可能成立但仍缺少计算的模型在该情景提供 `winners=null`。只有资格已排除其在该世界的适用性时才能省略该世界。对同方法版本的不同假设使用各自的 `hypothesis_id`。模型分歧可保留共同最优为空以及对应的可能最优集合。任何世界缺少所需覆盖时，两个全域集合均保持未知。结果计数没有概率意义。相同条件下的模型输出保持分别可查。

宿主取得当前端口后重建计划，把客户端续算状态视为不可信输入。检查点 MAC 绑定算法版本、完整计划、位置及已计算分区。范围、输入、证据或权限变化时，重新获取宿主状态以拒绝旧令牌，并丢弃过期结果。宿主在自己的授权边界保存密钥，并在正式发布前原子地复核当前状态。令牌签名只保证该状态由持有密钥的宿主签发，令牌不能自行授予访问权。检查点中的支持集合以十六进制文本传递，避免跨端整数精度损失。

最多允许 256 个世界、16 个竞争假设和 24 个行动，金额使用指定离散单位的非负整数。可暂停的预算计数限定组对谓词，输入验证、分组、排序、签名及序列化受合同规模上限约束。当前候选没有做设备 CPU 或内存硬预算验收。提前停止可证明已计算分支存在分歧，完整域的覆盖仍应单独读取。数学候选可以通过只读研究登记发现，正式方法注册表尚未接受这些候选，研究脚本只运行虚构数据。本模块尚无产品服务中的多阶段续算路由、持久检查点存储或独立科研验收。

## 复算

从 `platform/future_model` 运行以下入口。

```bash
.venv/bin/python scripts/v08_composition_replay.py
.venv/bin/python -m pytest -q tests/test_v08_composition.py tests/test_v08_descriptive_math.py
```
