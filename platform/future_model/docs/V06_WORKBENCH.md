# v0.6 中文使用与接口说明

## 从一句话开始

在 `platform/future_model/` 使用 Python 3.12、Node 24 和原有锁定依赖。

```bash
bash scripts/install.sh
bash scripts/run.sh --data /workspace/psychohistory-data serve --port 8765
```

打开 `http://127.0.0.1:8765/`，使用本地数据根的令牌连接。说出你正在考虑的问题，例如「我想换工作，但是不知道值不值得」。首答会组织目前的差异和一个优先问题。可以用一句话补充，也可以核对系统从原话找到的选项或条件。确认只表示这些是你认可的输入。

1. 核对选项和当前底线。影响底线的内容优先呈现，资料不足会显示待核实。明确修改一项已确认的条件时，选择要替换的旧项。若说法互相冲突，先核对来源与口径。
2. 有足够资料后，展开详细分析看单位、来源、假设、模型适用性、可行性和计算依据。高级输入沿用 v0.5，可补充有来源的评分、偏好、情景与概率证据。条件调整会重新分析。旧的图表不会沿用到新一轮。
3. 确定一项方案后，可以单独确认触发行动计划。实际行动及回访另行记录。保存需要活跃的本地授权和对这条记录的明确确认。事后偏好可单独采用。培训、研究和个性化用途暂无数据传输或模型写入能力，界面独立标注。
4. 结束会话或离开个人界面会清理当前页面的临时内容。服务端使用限量内存会话和访问期限。授权保存的记录仍需重新连接才能读取。导出的签名文件为明文，外部下载或系统快照由你保管。

旧入口 `/?workflow=v05` 和 `/?workflow=v04` 可继续运行，保留老 API 和 CLI 入口。v0.6 可查看、删除、撤回、导出、恢复及回访既有记录，修改旧快照的旧版参数使用 v0.5 工作台。

## 决策契约

| 接口或字段 | 语义 |
| --- | --- |
| `/api/v6/decisions/status` | 对话与实际计算引擎版本、本地配置和证据状态 |
| `/start`、`/turn` | 原文与补充回复。可明确设置本轮 `use_local_model`。服务器返回一个优先追问及待核对资料 |
| `/confirm` | 当前 `session_id`、会话 `revision`、选择的声明及方案，明确核对比较范围。更改和略过使用不同字段。第三方模型无法访问这个权限 |
| `/analyze` | 使用当前已核对输入。手动补充高级状态须明确确认、保持原问题身份、证据和底线来源 |
| `/select`、`/plan` | 当前可行选项的明确选择及触发计划。记录计划不执行外部操作 |
| `/save`、`/end` | 当前授权代次下保存这条已分析的版本，或结束临时会话。备份、历史和复盘沿用 v5 路径 |
| `/models` | 只列可用的确定性版本。C035、C036 与未达到准入要求的研究保留在候选档案 |

CLI `decision-v06` 读标准输入，每行一个 `{"operation":"start","data":{"question":"我想换工作，该先核对什么？"}}`。后续行用同一进程返回的会话 ID 和修订，退出后临时信息不可继续操作。同样可使用既有 `decision-v05` 复算已确认的底层状态。保存记录附当前输入摘要和计算版本，另带已核对证据收据、来源元数据及选项计划。未核对的整段对话不会自动打包保存。

证据区分用户确认、估计、假设、合成、未知及经独立证明的外部来源。核对界面不能授予独立外部验证，当前默认无外部核验服务。适配器或程序化来源可提供版本、发布时间、读取时间、时间范围和人群。冲突、不相容或缺失的数据不自动落入数学计算。

## 可选 Mac Ollama 与手机

Mac 上已有 Ollama 和白名单模型时，可用 `PSYCHOHISTORY_LOCAL_AI=1` 启动本地服务。本轮请求还需主动选用本地模型。仅连接 `127.0.0.1:11434`，默认关闭，默认白名单模型 `qwen3.5:4b-q4_K_M`。无服务、超限、拒绝或不可信结构时继续确定性澄清。模型只贡献逐字出现的候选片段和待查方法线索。计算、证据确认、保存和行动权限均由确定性入口控制。

移动安装及离线范围见 [移动端说明](../../mobile/README.md)。在手机自身安装的页面中，支持的数学在本机离线运行。此候选没有实现手机转发到 Mac 的私有模型代理，即使 Mac 在线也不自动接通。iPhone 真机、用户 Mac 上的真实 Ollama 和首次使用者体验须分别验证。
