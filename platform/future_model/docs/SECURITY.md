# 科学准入、威胁模型与安全边界

工程状态、科学证据、执行许可分开记录。只读发现可自动登记路径/哈希/原始元数据，permission=BROWSE_ONLY；不导入或执行第三方 Python。R 系列与其他来源的原始 JSON 字段、原命名空间和证据级别保留，不映射 MARKET 等级，不因测试通过升级。

v0.1 的唯一执行准入 SYNTHETIC_ONLY，仅内置个体和群体机制及公开合成数据。REAL_EXPERIMENT、冻结协议变更、科学升格、模型熔炼、公开部署、费用调整均拒绝。未来真实科研审批必须另建受审查协议，不能把当前合成审批按钮用于真实资料。

API：默认环回，同源、Bearer 令牌、写请求体大小预算；敏感读写均在后端验证，无宽松 CORS。令牌以 0600 文件保存、只进入页面内存、不写 localStorage/日志/Git/备份。健康接口仅含非敏感状态。API 默认不开 Swagger 和 schema 调试页。此版本没有多用户认证/公网防护体系，不应绑定 0.0.0.0 或通过外部隧道发布。

路径：科研读取限制在既有科研目录内的 JSON/Markdown 元数据（≤1 MiB），拒绝绝对路径、.. 和符号链接，不执行下载内容。数据根、对象和备份路径拒绝符号链接；内容寻址对象必须是 SHA-256 标识；恢复清单只接受已知数据库、审计日志与对象路径。

运行：每次真实 spawn 独立受信任进程，单并发、队列上限、墙钟超时、取消、CPU/内存预算及错误记录。Linux 通过 RLIMIT_CPU/RLIMIT_AS 强制；其他系统若不能强制会明确 NOT_ENFORCED。Linux worker 设置父进程死亡信号并核对父 PID，避免调度器被强杀后继续计算；其他平台对此明确 NOT_ENFORCED。进程隔离不等于恶意插件沙箱，未知第三方代码需要额外审查和更强隔离，本版不执行它。

不导入个人健康/财务数据。数据库、token、临时 staging 与 node_modules 不提交。科研收据只选公开仓库中一个既有 R233 元数据示范。云端网络 restricted/package_managers；PR 操作额外需要 api.github.com，Git 代理认证不证明 API 已可用。没有计费服务、GPU、云数据库、自动部署或新增 CI。
